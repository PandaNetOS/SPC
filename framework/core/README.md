# framework/core/ — 框架核心

> **本目录存放彩种无关的计算核心。** 它从 `games/<id>/game.yaml` 读取参数，
> 不硬编码任何具体彩种的数值。

## 应当放什么

| 模块 | 职责 | 说明 |
|---|---|---|
| 号码空间计算 | 由 `machine.zones` 算出单注组合总数 `T` | `T = ∏ C(pool_size_i, pick_i)` |
| 特征计算 | 由 `features` 段声明驱动，对一注号码算派生特征 | 框架不知道"连号"是什么，只执行声明 |
| 组合枚举 | 全枚举候选组合空间（用于精确理论分布） | 大乐透：324632 个前区组合 |
| 撞号权重模型 | 用 `features` + 观测数据校准人群偏好 | 参数来自结论（如 `F-0004` 的 α） |

## 关键约束

```
framework/core/ 里禁止出现：
  ✗ 数字 35 / 12 / 5 / 2（号码池参数）
  ✗ 字符串 "dlt" / "大乐透"
  ✗ 特征名如 "adjacent_pairs"（应从 game.yaml 读）
  ✗ 硬编码的概率值（应从 game.yaml 算）

framework/core/ 里应当出现：
  ✓ 从配置读取 machine.zones 并计算 T
  ✓ 按 features 段的 formula 求值
  ✓ 通用的 Bootstrap / 置换检验 / 枚举工具
```

## 与 `games/<id>/data/tools/` 的关系

| | `framework/core/` | `games/<id>/data/tools/` |
|---|---|---|
| 范围 | 彩种无关通用 | 该彩种专用（含字段口径） |
| 状态 | 待实现 | 已实现 |
| 迁移方向 | ← 从后者提取 | → 提取到前者 |

迁移时的判定标准：**这段代码换一个彩种能否直接用？**
- 能（只需换配置）→ 迁到 `framework/core/`
- 不能（依赖特定字段名/口径）→ 留在彩种目录
