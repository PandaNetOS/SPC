## 1. 核心推导

### 1.1 单注中奖概率的构成

设某彩种的号码空间为若干区（如大乐透：前区 C(35,5)、后区 C(12,2)）。

```
单注组合总数  T = ∏ C(pool_size_i, pick_i)
      大乐透：T = C(35,5) × C(12,2) = 324632 × 66 = 21,425,712
```

一等奖要求命中全部区。

```
P(一等奖 | 单注) = 1 / T
      大乐透：1 / 21425712 = 4.667289469773513e-08
```

**关键：这个分母只由号码空间决定。**

### 1.2 单注期望回报的分解

```
E[回报 | 单注] = Σ_j  P(命中奖级 j) × 该注在该奖级分得的金额

其中：
  P(命中奖级 j)  ——  由 T 与该奖级的中奖条件决定，**与选号方式无关**
  分得金额        ——  由「该奖级总奖金池 ÷ 该奖级中奖注数」决定
                     ↑ 这一项**取决于有多少人与你选中同一组合**
```

所以：

```
E[回报] = Σ_j  P_j  ×  ( 池_j / 中奖注数_j )
         └─固定─┘    └── 唯一可被选号影响的量 ──┘
```

### 1.3 因此，只有三件事是可能的

| # | 方向 | 是否可能 | 依据 |
|---|---|---|---|
| (a) | **提高中奖概率** | ❌ **数学上不可能** | 分母 T 固定，选号无法作用于"开奖结果"这个分子 |
| (b) | **降低撞号（减少与他人重号的概率）** | ✅ **可行** | 作用于上式的"中奖注数"分母 |
| (c) | **提高中奖时的奖金水平** | ⚠️ **部分可行** | 依奖池累积状态、封顶规则决定 |

**这是本仓库对外输出的全部策略空间。** 任何超出这个空间的声称都是错的。

## 2. 为什么 (a) 不可能 —— 严格的论证

### 2.1 论证

设你选组合 `c`，开奖结果为 `R`（随机变量，均匀分布于全部 T 个组合之上）。

```
P(命中) = P(R = c)
```

在均匀开奖假设下 `P(R = c) = 1/T`，**对任意 `c` 恒成立**。

选号策略 `S` 是一个从历史信息到组合的映射：`c = S(history)`。
因为 `R` 独立于 `history`（下一期开奖与历史无关，见序列不可预测性结论），

```
P(命中 | S) = P(R = S(history)) = 1/T     ← 与 S 无关
```

**结论：`P(命中)` 恒为 `1/T`，无论 `S` 是什么。**

### 2.2 唯一能推翻它的路径

只有一种情况能推翻：**开奖不是均匀随机的** ——
即存在可利用的物理偏倚（某球更常被摇出）。

这时分母不再是 `1/T`，而是某个倾斜分布 `π(c)`。

**但注意**：即使偏倚存在，要**可利用**还须满足：

1. 偏倚足够大（小偏倚的可利用性需要极大量样本才能兑现）
2. 偏倚**稳定**（不随球组更换/设备维护漂移）

本仓库的历史检验结论是：**均未发现可用的物理偏倚**
（见 `games/dlt/iterations/round02/known_errors.md` E1–E7，
以及 `HYPOTHESES.md` 的 H-003 —— 唯一可能的路径需要外部设备数据，当前不可检验）。

### 2.3 为什么不能用模拟"验证"这一点

一等奖概率是 `4.667e-08`。

要观察到有统计意义的命中次数，需要 `10^8` 量级的样本。
在有限算力下命中数**几乎恒为 0**，结论完全由采样噪声主导 —— **既证不了也驳不了**。

更根本的是：**这是数学定理，不是统计假设。** 不存在"用数据检验定理"这回事。

> 教训编码：`LESSONS.md` **L8**。
> 正确做法：概率不变性用**解析**给出；只有"撞号 / 奖金"这类必须估计的量才用模拟。

## 3. 为什么 (b) 可行 —— 机制

### 3.1 奖级总奖金池是固定的（当期）

以浮动奖为例：当期用于某奖级的奖金总额 `池_j` 由规则确定（与销量挂钩），
**不取决于中奖组合是什么**。

因此该奖级每位中奖者分得：

```
单注奖金额_j = 池_j / 中奖注数_j
```

**中奖注数越少，单注金额越高。** 且：

```
中奖注数_j = (买中该组合的注数) 的期望
```

若你选的组合是**冷门**（他人少买），而恰好中奖，则：

```
中奖注数_j 小  →  单注奖金额_j 高
```

### 3.2 但要注意：这只在中奖时兑现

```
E[回报提升] = P(中奖) × (奖金提升)
             └─4.67e-08─┘  └─ 有限 ─┘
```

极小概率 × 有限收益 = **极小的期望回报提升**。

以 2 元/注、返奖率 51% 计，**长期期望回报仍为负**。
(b) 改善的是"万一中奖时能拿多少"，**不是"能不能中"**，也不改变负期望的总格局。

### 3.3 可操作性来自"人群偏好"

若彩民的选号是均匀的，(b) 也无从下手 —— 无论选什么组合，撞号期望都一样。

(b) 可行**完全依赖**于一个经验事实：**彩民选号是非均匀的**。

已识别的偏好（见 `FACTS.jsonl`）：

| 偏好 | 证据 | 撞号比 |
|---|---|---|
| 连号（相邻数） | 一等奖注数比 | 1.3603 [1.1298, 1.6292] |
| 生日号（≤31） | 模型校准系数 1.25 | （估计） |

> ⚠️ 这些是**观测量**，不是解析结论。可信度 ★★★★☆ / ★★★☆☆。
> 引用时必须区分（见下方的"证据强度分级"）。

## 4. 为什么 (c) 部分可行

(c) 依赖两个机制：

| 机制 | 说明 | 可操作性 |
|---|---|---|
| **奖池累积** | 前期无人中出 → 本期一/二等奖池更大 | 需建模瓜分机制（未做，见 `Q-007`） |
| **封顶稀释** | 触发封顶后，减少同号人数**不再**提高单注奖金 | ⚠️ **反向**：削弱 (b) 的收益 |

**封顶稀释是本仓库对 (b) 最重要的减损项。**

现行大乐透规则（E6，2026-02-02 起）：一、二等奖**单期总额封顶 1 亿元**。
已实测触发（`F-0015`：26113 期 37 注一等奖 → 单注仅 239 万元）。

**触发封顶后**：

```
池_j 已被压缩至上限  →  中奖注数减少  →  单注金额不再提升
```

因此给现行规则的建议**必须**带此减损。当前对外输出的 +121%（`F-0004`）
是**未计封顶的上界**。

## 5. 三类策略的可行性判定（模板）

每个彩种在 `strategy.json` 里应对应本节结构：

| 类型 | 可行性 | 数学依据 | 期望值影响量级 |
|---|---|---|---|
| (a) 提高中奖概率 | ❌ 不可能 | 各奖级恒定：一等奖 `P = 1/T` | 0（且声称能做即违反红线） |
| (b) 降低撞号 | ✅ 可行 | `单注奖金 ∝ 1/中奖注数` | 中奖时奖金提升；期望回报提升极小 |
| (c) 提高奖金水平 | ⚠️ 部分可行 | 奖池累积 / 封顶稀释 | 需建模；可能为负（封顶） |
