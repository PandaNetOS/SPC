## 0. 一句话总纲

> **宁可标 `tentative`，不要标错 `established`。**
>
> 本仓库的可信度来自**保守**。一条标着 `tentative` 但边界清楚的结论，
> 比一条标着 `established` 但模糊的结论有用得多。

## 1. 建模前检查

### 1.1 因变量分布诊断（防 L1）

```python
y = df['prize1_winners']            # 计数因变量
vr = y.var() / y.mean()
print(f'var/mean = {vr:.3f}')       # 大乐透一等奖注数：8.46
```

| `var/mean` | 处理 |
|---|---|
| ≈ 1.0（0.8–1.2） | Poisson 可用 |
| 1.2 – 1.5 | 慎用，建议 QuasiPoisson |
| **> 1.5** | **禁用 Poisson** → QuasiPoisson / NegBin2 + HAC |

**同时看偏度与极值**：

```python
print(f'mean={y.mean():.2f} median={y.median():.2f} max={y.max()}')
# 若 mean >> median，是重尾 → 触发 L5 检查
```

### 1.2 共线性诊断（防 L1 的"变量共线"分支）

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor
# VIF > 10 → 严重共线，必须处理（去掉一个或改用正交化）
```

> 大乐透实例：`heat` 与 `sum_z`、`span_z` 高度相关 → 系数符号会随定义翻转。

### 1.3 定义敏感性（防 L1 的"定义敏感"分支）

**同一概念若有两种合理定义，必须两种都测。**

> 大乐透实例：换 `heat` 的定义后，IRR 从 1.053 翻转为 0.842。
> 一个随定义翻转的"显著"，不是真信号。

## 2. 检验前检查

### 2.1 期望频数（防 L2）

```python
obs = np.array([...]); exp = ...
print(f'min expected = {exp.min():.2f}')     # < 5 → 禁用渐近卡方
```

| 最小期望频数 | 方法 |
|---|---|
| ≥ 5，且全部格 ≥ 5 | 渐近卡方可用 |
| **< 5** | **蒙特卡洛精确检验（B ≥ 10000）** |

> 大乐透实例：奇偶分布"0 奇"格期望仅约 56，
> 渐近卡方 p<1e-6，**MC 精确 p=0.126（不显著）**。

### 2.2 多重比较（防 L4）

**若做了 k 个检验，不可只看单个 p 值。**

正确顺序：

1. 构造**经验零分布**（置换检验，B ≥ 10000）
2. **家族错误率校正**（如 max|r| 联合检验）
3. **必须做样本外验证**（时间序列外推，报 R²）

> ⚠️ **FDR 校正不能替代置换检验。** 二者回答不同问题：
> - FDR：控制假发现比例
> - 置换：某统计量在零假设下的分布是什么
>
> 大乐透实例：ACF lag 6/10/18/23 在 FDR 后"存活"，
> 置换检验家族 p=0.0004（信号为真），
> **但样本外 R² = −0.083（信号无用）**。

### 2.3 分期稳健性（防 L3 的时段陷阱）

**任何结论都应在关键断点前后分段复验。**

```python
# 至少一段：用已定位的结构切点（大乐透为 2013-08）
seg1 = df[df.index < cp]; seg2 = df[df.index >= cp]
# 报告两段的效应量 + 符号一致性
```

| 结果 | 判定 |
|---|---|
| 两段同向且幅度接近 | ✅ 稳健 |
| 两段同向但幅度差大 | ⚠️ 需声明适用时段 |
| **仅一段显著** | ❌ **只能声明该时段的结论** |

> 大乐透实例：连号**开出率**优势仅早期显著（后期 p=0.356）→ 不可作为当前规律。
> 而连号**撞号**效应两奖级同向 → 稳健。

## 3. 变点分析专项（防 L3）

**禁止按自然年硬切。** 正确流程：

```
1. 全候选切点扫描：t ∈ [300, n-300]，步长 ≤ 10
   统计量：2×k 列联表卡方（k = 号码空间大小）
2. 交叉验证：ruptures 多模型（Pelt/Binseg × l2/rbf 核）
3. 画"切点-统计量"曲线，判断峰形
4. NYblom / CUSUM 结构稳定性检验
5. Power analysis 排除"样本量解释"
6. ⚠️ 检查候选混杂变量是否同位置（规则变更、销量、设备）
```

**判据**：

| 现象 | 结论 |
|---|---|
| 单点尖峰 | 突变 |
| **宽峰**（多个相邻 t 都很高） | **渐变**，切点有不确定性 |
| 多方法一致 | 可信 |
| 仅有自然年方法支持 | **不可信** |

> 大乐透实例：最优 t=960（2013-08-28），χ²=185.0，排名 1/234；
> 但 t=930~1000 都很高 → **渐变**，±6 个月不确定性。
> Pelt 独立给出 2013-08-14（一致）。

## 4. 模拟专项（防 L8）

**写模拟前先问三个问题：**

```
Q1. 这个量能解析给出吗？
    → 能 → 解析给出，不要模拟
Q2. 能精确枚举吗？
    → 能 → 枚举，不要模拟（枚举是「真值」，模拟是「估计」）
Q3. 是否必须估计？
    → 是 → 可以模拟，但必须：
        ① 声明模型与假设
        ② 给出自由参数的校准依据
        ③ 报 95%CI
        ④ 列出减损项
```

| 主张类型 | 正确方法 |
|---|---|
| 概率不变性 | **解析** |
| 形态被摇出的频率 | **精确枚举** |
| 形态是否集聚人群 | **观测量 + Bootstrap CI** |
| 中奖时奖金如何变化 | **条件份额模拟**（唯一必须模拟的量） |
| "能否统计检验" | **功效分析** |

### 4.1 模拟的强假设必须显式列出

> 大乐透实例：条件份额模拟依赖
> H2（彩民非均匀）、H3（注数 ∝ 购买量）、α=13.9405（由历史注数锁定）。
> 这些是**估计**，不是真值 —— 结论置信度只能给 ★★★☆☆。

### 4.2 功效分析（回答"为什么模拟也测不出"）

```
检出相对效应 ε 所需样本量 ~ 1 / (p · ε²)
大乐透：ε=1% → ~2.143e+09 期；历史总量不足 3000 期
```

**关键区分**（不可互相替代）：

- **"数学上不可能"** = 解析结论，**确定**
- **"统计上测不出"** = 功效不足，只说**这套数据无法检验**

## 5. 结果报告检查

### 5.1 每个数字必须四件齐全

| 项 | 要求 |
|---|---|
| **效应量** | 比值 / IRR / 差值（不要只报 p 值） |
| **不确定性** | 95%CI（无 CI 的估计不可引用） |
| **样本量** | n |
| **方法** | 精确/渐近、置换/参数、模型族 |

> ❌ 不合格："存在显著效应（p<0.05）"
> ✅ 合格："比值 1.3603，95%CI [1.1298, 1.6292]，n_ge2=292 / n_lt2=2641，观测+Bootstrap(2000)"

### 5.2 重尾变量的报告（防 L5）

```python
# ❌ 禁止
print(f'平均注数 = {y.mean()}')       # 被极端值主导

# ✅ 正确
print(f'中位数 = {y.median()}, IQR = {y.quantile(.75)-y.quantile(.25)}, max = {y.max()}')
```

| 目标 | 正确方法 |
|---|---|
| 描述 | 中位数 / 分位数 |
| 组间比较 | Mann-Whitney U / GLM（含过度离散校正） |
| 效应量 | **IRR 而非均值差** |

> ⚠️ 已知未偿技术债：`F-0003` 的 1.3603 是**均值比**，触及本项。
> 缓解：二等奖（样本量约 80 倍）交叉确认 + Bootstrap CI。
> 改进：见 `workbench/TODO.md` 的 `T-002`。

### 5.3 概念分离（防 L7）

**"开出率"与"被选中率"必须在不同小节、用不同措辞。**

| 概念 | 定义 | 大乐透值 | 可用性 |
|---|---|---|---|
| 开出率 | 某形态被**摇出**的频率 | run≥2 比值 1.120 | ❌ 仅早期 |
| 被选中率 | 某形态被**人买**的密度 | 一等奖注数比 1.360 | ✅ 可避开 |

**自检**：报告里若同一段同时出现"更易开出"和"更多人中" → 立即拆分。

### 5.4 规则口径声明（防 L9）

**任何涉及奖金/奖级的结论，必须在 `evidence.rules_epoch` 声明所用版本。**

自检：

```
□ 是否按规则变更断点分段？
□ 是否声明了 epoch？
□ 是否避免了跨断点比较金额？
□ 若为号码类分析 —— 号码结构是否从未改变？（若是则无需分段）
```

## 6. 归因边界

> **"能排除什么"往往比"能证明什么"更有价值。**

| 可做 | 不可做 |
|---|---|
| 观测到 A 与 B 同时变化 | 断言 A 导致 B |
| 排除"规则变更导致"（因时间不同位） | 断言"设备更换导致"（无设备数据） |

**必须写明的两种边界**：

1. **数据边界**：本仓库只有开奖数据，无设备/球组/场地记录
2. **方法边界**：观察性数据只能给相关，因果需要实验或准实验设计

## 7. 收尾检查清单

复制到每轮 `FINDINGS.md` 末尾逐项打勾：

```
□ 所有计数因变量已算 var/mean；>1.5 的未用 Poisson
□ 所有列联表已查最小期望频数；<5 的未用渐近卡方
□ 多重比较已用置换 + 家族校正（不是仅 FDR）
□ 所有"预测"结论有样本外 R² / AUC

□ 变点分析未用自然年硬切；有 ≥2 种方法交叉验证
□ 重尾变量未用均值比较（或已声明并给了缓解）
□ 开出率与被选中率未混用
□ 模拟仅用于必须估计的量；已列假设与 CI
□ 奖金类结论已声明 rules_epoch，未跨断点比较
□ 每条结论的 caveats 非空
□ 每条结论的 source 文件真实存在
□ 每个数字有可独立复现的脚本
□ 已报告本轮推翻/失败/未验证的假设
□ 已报告期望证伪但未能证伪的内容
```

**任何一项未打勾，相关结论不得标 `established`。**

## 9. 新方法模块（r19 新增）

> 以下方法已实现为 `framework/core/stats.py` 中的可调用函数。

### 9.1 FDR 校正（Benjamini-Hochberg）

**什么时候用**：探索性研究（筛 k 个候选找信号）。

**与置换检验（FWER）的区别**：
- FWER（置换 max|r|）：控制"至少一个假阳性"的概率 → 确认性研究
- FDR（BH）：控制"假发现占总发现的比例" → 探索性研究

**用法**：
```python
from spc.core.stats import bh_fdr
reject, adjusted_p = bh_fdr(pvalues, alpha=0.05)
```

### 9.2 Rolling-origin 交叉验证

**什么时候用**：时序数据的样本外验证，只切一刀不够时。

**用法**：
```python
from spc.core.stats import rolling_origin_cv
splits = rolling_origin_cv(data, min_train=60, test_window=10, step=10)
```

### 9.3 贝叶斯因子

**什么时候用**：想知道"效应 > 0 的后验概率是多少"，而不只是"零假设对不对"。

**用法**：
```python
from spc.core.stats import bayes_factor_normal
result = bayes_factor_normal(observed_effect=0.3, se=0.1)
# result['bf10']: Bayes Factor
# result['post_prob_h1']: H₁ 后验概率
```

### 9.4 元分析

**什么时候用**：多条同主题结论需要合并出综合效应量。

**用法**：
```python
from spc.core.stats import meta_analysis
result = meta_analysis(effect_sizes=[0.2, 0.25, 0.18],
                       standard_errors=[0.05, 0.06, 0.07])
# result['fe_estimate']: 固定效应估计
# result['i_squared']: 异质性 I² (%)
```

### 9.5 前视偏差检查

**什么时候用**：写特征脚本后，检查有没有不小心用了未来数据。

**用法**：
```python
from spc.core.stats import check_lookahead_bias
result = check_lookahead_bias("scripts/feature.py")
```

### 9.6 confidence 自动评分

**什么时候用**：给 FACTS 条目打分时，不用人工凭感觉。

**用法**：
```python
from spc.core.stats import auto_confidence_score
result = auto_confidence_score(n=2000, effect_size=0.2,
                               robust=True, out_of_sample=True)
# result['score']: 1-5 分
# result['grade']: low/moderate/high
```

### 9.7 策略效果监控

**什么时候用**：策略落地后，持续监控预期效果 vs 实际效果。

**用法**：
```python
from spc.core.stats import monitor_strategy_effect
result = monitor_strategy_effect(expected_effect=-0.2,
                                 observed_effect=-0.15,
                                 observed_se=0.05)
# result['status']: ok / warning / critical
```

## 10. 预注册机制（r19 新增）

**核心原则**：区分探索性研究和验证性研究。

| 类型 | TASK_BRIEF 标记 | 结论状态 | 说明 |
|---|---|---|---|
| **探索性** | `exploratory: true` | 强制 `tentative` | 筛候选、找信号、试方法 |
| **验证性** | `confirmatory: true` | 可标 `established` | 验证某个特定假设 |

**为什么重要**：防止 p-hacking——试了 100 种定义后挑出一个"显著"的，当成发现。

**实现**：TASK_BRIEF 模板已加「研究类型」字段，收轮时 validate 检查。
