## Q-001 — 撞号效应（F-0003）的分期稳健性未验证

|---|---|

| **由何而起** | F-0003 的 `caveats` 第 2 条 |
| **具体问题** | 一等奖注数比 1.360 在 2013-08 前后两段是否同向？幅度是否稳定？ |

| **预计产出** | 更新 F-0003（填 `caveats`）或新增 F-xxxx |
| **优先级** | **高** — 直接影响 F-0004 这个唯一可用策略 |

| **具体问题** | 用中位数比 / 负二项回归 IRR 复核，1.360 是否仍然成立？ |
| **为何重要** | 一等奖注数是重尾分布（var/mean=8.46）。均值比可能被少数极端期主导。这是**已知未偿技术债** |

| **验收判据** | 三种估计方向一致且 CI 重叠 → 结论稳固；若中位数比显著低于均值比，须在 F-0003 声明 |
| **预计产出** | 更新 F-0003 或新增复核结论 |
| **优先级** | **高** — 这是纪律性欠账，不是锦上添花 |

| **具体问题** | 现模型只有"连号"和"生日号（<=31）"两个特征。能否估出 35 个号的逐号偏好向量？ |
| **为何重要** | 逐号偏好向量能显著提高 C 层估计的可信度（目前 ★★★☆☆）。这是把 F-0004 从"估计"推向"较强估计"的关键 |

| **验收判据** | 逐号权重向量 + 校准残差诊断；重跑条件模拟，比较 uplift 变化 |
| **预计产出** | 更新 F-0004，置信度可能上调 |
| **优先级** | **中** — 提升质量，但不阻塞当前输出 |

## Q-008 — 定义歧义：本仓库的"策略有效性"标准需明确

| 项 | 内容 |
|---|---|

| **由何而起** | 无单一 caveat；来自对全仓库定位的审视 |
| **具体问题** | 一个"负期望游戏"里，什么算"有效策略"？<br>· 提高期望回报？（数学上只有撞号规避这一条路，且幅度有限）<br>· 降低方差？<br>· 完全不改变期望、只改变体验？ |

| **预计产出** | 标准文档 + 可能的 schema 次版本更新 |
| **优先级** | **中** — 不阻塞技术工作，但影响对外表达的可信度 |

## 工作约定

1. **每个问题必须能被回答**。"了解更多关于 X" 不合格；"X 在 Y 条件下的幅度是多少" 合格
2. 问题答出后：新增 `F-xxxx` → 更新 `FACTS.jsonl` → 把本文件对应条 `状态` 改 `answered` 并**附上新结论 id**
3. 若问题被判定为"当前数据无法回答"，改标 `blocked` 并**写明缺什么数据**（这本身是有价值的结论）
4. 新问题从 `caveats`、失败的检验、以及外部评审意见中收集
5. 每轮迭代结束时，`HANDOFF.md` 必须引用本文件，并说明下一轮优先攻哪几个
