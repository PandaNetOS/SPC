## Q-002 — F-0003 用了均值比，未做中位数比对照（触及 L5）✅ answered in r03

| 项 | 内容 |
|---|---|
| **状态** | `answered` → **F-0018 新增** |
| **由何而起** | F-0003 的 `caveats` 第 1 条；`LESSONS.md` L5 的"自我审视"段 |
| **具体问题** | 用中位数比 / 负二项回归 IRR 复核，1.360 是否仍然成立？ |
| **为何重要** | 一等奖注数是重尾分布（var/mean=8.46）。均值比可能被少数极端期主导。这是**已知未偿技术债** |
| **方法** | ① 中位数比 + Bootstrap CI；② NegBin2 回归（含过度离散校正）给 IRR + HAC 标准误；③ 与均值比对照片 |
| **验收判据** | 三种估计方向一致且 CI 重叠 → 结论稳固；若中位数比显著低于均值比，须在 F-0003 声明 |
| **预计产出** | 更新 F-0003 或新增复核结论 |
| **优先级** | **高** — 这是纪律性欠账，不是锦上添花 |
| **✅ 结果（r03）** | 均值比 1.3603、中位数比 **1.5** [1.5, 2.0]、NB2 IRR 1.3603（alpha_MLE=1.0034，HAC [1.1352, 1.6301]）—— 方向一致、CI 下界均 > 1。L1 检查：var/mean=8.46 >> 1（须 NB2）。L5 截尾检验：剔除 P99 后均值比仅变化 **1.72%** → 重尾不主导。**技术债清偿**。注：NB2 log 链接下 IRR ≡ 均值比，独立证据是中位数比。脚本 `round03/scripts/b2_robust_estimators.py` |

## 工作约定

1. **每个问题必须能被回答**。"了解更多关于 X" 不合格；"X 在 Y 条件下的幅度是多少" 合格
2. 问题答出后：新增 `F-xxxx` → 更新 `FACTS.jsonl` → 把本文件对应条 `状态` 改 `answered` 并**附上新结论 id**
3. 若问题被判定为"当前数据无法回答"，改标 `blocked` 并**写明缺什么数据**（这本身是有价值的结论）
4. 新问题从 `caveats`、失败的检验、以及外部评审意见中收集
5. 每轮迭代结束时，`HANDOFF.md` 必须引用本文件，并说明下一轮优先攻哪几个
