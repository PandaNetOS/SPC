## H-001 — 连号偏好源于"随机性错觉"

| 项 | 内容 |
|---|---|
| **状态** | `unverified` |
| **假设** | 彩民避开连号是因为认为"连号看起来不像随机"，这是一种**代表性启发式偏差**（representativeness heuristic） |
| **已有证据** | F-0003 观测到连号形态人群密度高（比值 1.360）；F-0005 显示**连号开出率并无优势** → 说明偏好不是基于"彩民学到的规律" |
| **可证伪的预测** | ① 若为随机性错觉，则其它"看起来不随机"的形态也应人群偏多 —— 如全奇数、全大号、等差序列（1-7-13-19-25）；② 效应应与**教育/数学素养**负相关（数据不可得，间接代理：按省份/年份的销量结构）|
| **检验方法** | 用 `prize2_winners`（样本量大）构造各形态的人群密度代理，比较"看起来随机"与"看起来不随机"两组；特别测等差数列（如 5-10-15-20-25）的撞号程度 |
| **价值** | 若成立，可**系统性地枚举**所有"看起来不随机但实际等概率"的形态，找到更多可避开的高撞号区 —— 直接增强策略 |
| **风险** | 数据只有注数，无法观察个体动机。极端情况下只能得到相关性，因果归因**超出数据范围**（见 `../lessons/LESSONS.md` L6 的归因边界精神）|
| **优先级** | 中高 |

## H-002 — 生日号偏好可用"最大号 ≤ 31"之外的更细结构刻画

| 项 | 内容 |
|---|---|
| **状态** | `unverified` |
| **假设** | 生日偏好不是"`max ≤ 31` 一刀切"，而是**按号递减**：1–12 最强（月），13–31 次之（日），32–35 最弱。且**后区**（1–12 全在月范围）偏好应最强 |
| **已有证据** | F-0004 的现有模型用了 `max(c) ≤ 31 → ×1.25` 这个粗糙的布尔代理；原策略模拟 README §9 第 1 条明确列为待改进 |
| **可证伪的预测** | 用 `prize2_winners` 回归估出的逐号权重，应在 1–12 显著高于 13–31、高于 32–35 |
| **检验方法** | `prize2_winners ~ Σ w_i · I(号 i 出现) + 销量控制 + 形态控制`；或直接用 35 个号的边际频次构造权重向量 |
| **价值** | 直接把 F-0004 的 C 层估计从"单一 α 校准"升级为"逐号权重校准"，可信度可从 ★★★☆☆ 提升 |
| **风险** | 逐号权重与"连号偏好"可能共线（连号常在小号区），需 VIF 诊断 |
| **r04 旁证** | F-0025 已证实**后区被选中率非均匀**（过散布 8.72×，最热 9 号 / 最冷 12 号，组合密度比 2.25×）—— 与本假设"后区偏好强度不同"方向一致，但**具体排名与"1–12 递减"的预测不符**（12 号最冷）。逐号递减的完整检验仍待 Q-006 |
| **优先级** | 中（并入 Q-006）|

| **已有证据** | F-0015 观测到 26113 期 37 注触发封顶；F-0012 显示销量有星期效应；现行规则下奖池 ≥8 亿时三至七等奖升 20%–40% |

## H-005 — 撞号效应在"周六"期更强

| 项 | 内容 |
|---|---|
| **状态** | `refuted`（r05：方向相反，且幅度不构成可利用择时） |
| **假设** | 星期六销量最高（F-0012），而高销量期彩民更多是"休闲型"购彩者（更依赖直觉/随机点选），因此**撞号集中度在周六更高** → 避开热门的收益在周六更大 |
| **已有证据** | F-0012（销量星期效应 p=0.0004）；F-0003（撞号效应存在） |
| **可证伪的预测** | 分星期比较连号形态的一等奖注数比：周六的比值应显著高于周一/周三 |
| **检验方法** | `prize1_winners` / `prize2_winners` 按 `weekday × run_ge2` 分组做交互项回归；或分组 Bootstrap 比值 |
| **价值** | 若成立，策略规则可加"择日"维度 —— 这是**第二条独立于 F-0004 的规则**，且不依赖新数据 |
| **风险** | 分四组后样本量下降（周六约 976 期，其中 run≥2 约 100 期），CI 会变宽。需注意**多重比较**（3 个星期 × 2 个奖级 = 6 次比较）|
| **优先级** | 中高 —— 若成立收益明确，且检验成本低 |
| **r05 裁定** | ❌ **证伪（方向相反）**：后段 NB2（控制销量）的 `run×周六` 交互**显著为负** —— w1 −0.268（p=0.039）、w2 −0.607（p<0.0001），即**周六的连号撞号效应更弱**（尤其二等奖口径；Holm 校正后仅 w2 保留）。但 Bootstrap 两两差 CI 全含 0、幅度小，**不构成可利用的择时因素** → 维持 F-0023/A-009（新增 **F-0030**）。假设本身的方向（周六更强）被数据拒绝。**保留本条记录，不删除**（假设池的纪律） |

## H-006 — 节假日窗口的连号撞号效应偏低（r05 新增，tentative）

| 项 | 内容 |
|---|---|
| **状态** | `unverified` |
| **假设** | 国庆/元旦等休市窗口前后，购彩人群构成不同（更多随机型/非偏好型买家稀释连号密度），使该窗口的连号撞号效应低于基线 |
| **已有证据** | F-0032（探索性：国庆窗口连号比 0.72 vs 基线 1.28，元旦 0.73 vs 1.27；样本 n=82/67，CI 宽）；F-0030（周六效应方向相同的"人群构成稀释"解释） |
| **可证伪的预测** | 用更严谨的窗口定义（农历精确映射的春节前后期次）与更大样本复验：若节假日窗口的连号注数比显著低于全年基线，则 H-006 成立 |
| **检验方法** | ① 农历春节日期精确映射（2007–2026），构造节前/节后 N 期窗口；② 与 F-0030 相同的 NB2 交互模型 + Bootstrap 分组检验；③ 按后段为主 |

| **风险** | 窗口定义自由度大（节前/节后几天）→ 需固定规则避免 p-hacking；样本量小 |
| **优先级** | 低（P2，探索性） |

## 假设的生命周期

```
OPEN_QUESTIONS.md 的"问题"（无方向）
        ↓ 形成方向性猜测
HYPOTHESES.md 的"假设"（有方向，未验证）
        ↓ 通过检验
FACTS.jsonl 的"结论"（已验证，带证据与 CI）
        ↓ 若被推翻
"结论" → status=refuted / superseded（保留在台账）
```

**注意方向**：假设池是**单向**的 —— 假设可以升级为结论，但结论**不会**退回假设。
结论被推翻后保留在台账里标 `refuted`，这是纪律（见 `spec/VERSIONING.md`）。

---

## 新增假设的操作步骤

1. **必须包含"可证伪的预测"** —— 说不出"什么观测会推翻我"，就不能进本文件
2. 填全五段：**假设 / 已有证据 / 可证伪的预测 / 检验方法 / 价值与风险**
3. 显式引用已有 `F-xxxx`（假设不能凭空产生）
4. 若判定为**当前数据不可检验**，标 `unverifiable_with_current_data` 并写明缺什么数据
   —— 这比删掉它有价值得多
5. 假设被验证后：新增 `F-xxxx` → 本文件该条改 `verified (→ F-xxxx)`
6. 假设被明确推翻后：本文件该条改 `refuted (理由)` —— **不删除**
