# smartpickcore

> PandaNetOS 智能选号核心（Smart Pick Core）

号码组合空间上的「形态感知」选号与撞号规避核心库。

## 定位

在**不改变中奖概率**的前提下，通过避开高人群密度形态（连号、生日号等），
降低中奖时的同号人数，从而提高**中奖时的期望奖金**。

- 中奖概率 = 1 / 21,425,712（前区 35 选 5 × 后区 12 选 2）——**不可改变**
- 可优化的量：撞号系数（决定奖金被多少人分）
