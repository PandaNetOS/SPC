## 1. 数学底线

```
前区  C(35,5)  = 324,632
后区  C(12,2)  =      66
单注组合总数 = 324,632 × 66 = 21,425,712
一等奖概率   = 1 / 21,425,712 ≈ 4.667e-08
```

**选号方式不能改变中奖概率。** 这是解析结论，不依赖数据：
分子（是否命中）由开奖结果决定，选号无法影响。

选号唯一能影响的是**分母**——是否与他人共享奖金。

## 2. 可优化的量：撞号系数

给定"我们中了一等奖"，同期同号人数越多，单注奖金越低。
撞号系数定义为：

```
collision_factor = 开奖组合的人群权重 / 全体组合平均人群权重
```

人群权重模型由历史中奖注数校准：

```
w(c) = α       若 run(c) ≥ 2       （连号偏好）
     × 1.25    若 max(c) ≤ 31     （生日号偏好）
     = 1       否则
α = R × P_lt2 / P_ge2            （R = 观测一等奖注数比值）
```

校准结果：`α = 13.9405`（R = 1.3603，P_ge2 = 0.0889）。

## 3. 效应量

| 策略 | 撞号系数 |
|---|---|
| 随机选号 | 1.0028 |
| 避开连号（run = 0） | 0.4528 |

比值 **0.4515**，95%CI **[0.4487, 0.4543]** → 中奖时期望奖金提升 **+121.5%**。

## 4. 三道减损（必须计入）

1. **模型估计误差**：α 与生日偏好系数来自历史注数近似校准，不是真值。
2. **封顶稀释**：现行规则一、二等奖单期总额封顶 1 亿元、单注最高 500 万；
   已触发封顶时，减少同号人数不再增加单注奖金。
3. **只在中奖时兑现**：中奖概率 4.667e-08 不变，长期期望回报仍为负。

## 5. 明确排除的方法

| 方法 | 排除依据 |
|---|---|
| 追冷号 / 追热号 / 算遗漏 | 号码分布已收敛均匀 |
| 历史频率选号 | 偏差仅存在于早期 |
| 星期 / 周期选号 | 号码无星期效应；ACF 样本外 R² 为负 |
| ML / 神经网络预测 | R² 全负，AUC ≈ 0.5 |
| 选"冷后区" | 后区独立均匀 |
| 依据"预测"加倍投注 | 无预测能力，只放大亏损 |
