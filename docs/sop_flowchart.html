SPC 标准操作流程（SOP）

① 开轮
• 写 TASK_BRIEF.md（目标 / 验收判据 / 输入 / 方法 / 陷阱提醒）
• 更新 versions.json：current_iteration → rNN+1
↓
② 执行
• 跑分析脚本 scripts/*.py（记录种子、B 值、数据版本）
• 写 FINDINGS.md（结论 + 数字 + CI + 证伪章节）
↓
③ 证据入库（三闸门）
G1 schema → 格式合规（claim / confidence / source_sha256）
G2 矛盾检测 → 与已有结论冲突？降 tentative 或拒绝
G3 锚定 → source 文件 SHA256 锚定，漂移可检出
通过后写入 FACTS.jsonl（Add / Modify / Supersede 原子操作）
↓
④ 收轮
• 写 HANDOFF.md（结论 / 遗留问题 / 下轮建议 / 风险提示）
• 写 manifest.json（deliverables + upstream_fact_ids + strategy_updated）
↓
⑤ validate --all（自动校验，全绿才能 commit）
✓ 四件套完整（manifest 配 FINDINGS / TASK_BRIEF / HANDOFF）
✓ TASK_BRIEF 内容完整（含目标/验收/输入/方法）
✓ FINDINGS 证伪章节（含推翻/修正/证伪/未验证/失败）
✓ HANDOFF 结构化（4+ 段，命中 3/6 关键词）
✓ deliverables 文件实际存在
✓ upstream_fact_ids 在 FACTS.jsonl 里真实存在
✓ 策略文档同步双保险（follows_current + mtime 对比）
✓ 轮次号对账（最新已收尾轮 ≤ current_iteration）
✓ 目录轮次护栏（目录最大轮次 ≤ current_iteration）
↓
⑥ commit + push
• 用户确认后 push 到远程 main
• 收轮辅助脚本：tools/finalize_round.ps1（git diff 自动生成 manifest 草稿）
↻ 下一轮（迭代链不断）

策略落地路径（从发现到规则）

宽筛发现效应
↓
Bootstrap 95% CI + 分期稳健性
↓
置换检验 max|r| 多重比较校正
↓
重尾稳健复核（中位数 / 截尾均值）
↓
时序 hold-out 样本外验证
↓
用户批准（红线：未经批准不得落地）
↓
写入 strategy.json（带 effectiveness_grade）
A 档 数学恒真：解析可证 → R-002
B 档 统计确立：观测显著 + hold-out → R-001 / R-003 / R-004
C 档 模型估计：样本有限，标注假设 → R-005

红线（任何 SOP 不得违反）

1. 选号不改变中奖概率（各奖级概率恒定）
2. 负期望游戏 —— 策略只影响"中奖时分多少"
3. 未经用户批准不得落地策略规则
4. 未经用户确认不得 push 远程
5. 远程节点（192.168.30.51）数据不得删除
6. 测试数据必须在 D:\test\ 下，不得污染仓库目录
