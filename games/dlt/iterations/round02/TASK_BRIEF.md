> ④ 与官方开奖公告逐期核对最新若干期；⑤ 总期数与独立新闻口径交叉验证。

### 字段口径（易错点）

| 字段 | 口径 / 陷阱 |
|---|---|
| `draw_num` | **字符串**类型（`'07001'` 带前导零，`'26115'` 不是数字 26115） |
| `weekday` | 中文单字（一/三/六） |
| `front_sum` | 前区 5 数之和，范围 15~165 |
| `front_big` | 大号 = **≥18** 的个数（0~5） |
| `prize1_winners` | 一等奖注数，**重尾分布**（均值≈3.86 / 中位 2 / 最大 106 / var/mean≈8.46） |
| `prize1_amount_yuan` | 一等奖单注奖金，**81.4% 期数封顶 500 万**（右删失！）；**封顶规则多次变更**，见 `06_RULES_HISTORY.md` |
| `pool_yuan` | **本期期末奖池**（即滚入下期的奖池），非本期起始奖池 |
| `sale_yuan` | 全国销售额（元） |

### CSV 编码

`01_data/*.csv` 均为 **UTF-8 with BOM**。读取必须：

```python

```

## 2. 数学底线（任何分析都必须尊重）

```
单注组合总数      = 21,425,712
一等奖概率        = 1 / 21,425,712 = 4.66728947e-08
每 2 元投入的数学期望回报 ≈ 1.02 元（现行返奖率 51%）
```

**推论：**
- **不存在能提高中奖概率的选号方法**，除非能证明摇奖物理过程存在可利用偏倚（见优先任务 T3）。
  这一点是**解析结论**，不依赖任何数据。
- 可被真正影响的方向只有两个：
  1. **降低撞号概率**（同概率下分到更多奖金）——分奖结构效应（**已验证存在**，见 `07_strategy_simulation/`）；
  2. **提高中奖时的奖金水平**（浮动奖金池/奖池累积期）——需建模奖金瓜分机制。

## 4. 已知的方法论陷阱（历史轮次踩过的坑）

| # | 陷阱 | 后果 |
|---|---|---|
| E1 | 对过度离散计数数据用 Poisson | 标准误严重低估 → 伪显著 |
| E2 | 对小期望格用渐近卡方 | 伪显著（奇偶分布案例） |
| E3 | 变点用"自然年硬切" | 断点定位错误（偏了近 2 年） |
| E4 | 用 FDR 校正替代置换检验 | 无法判定 ACF 存活项的真伪 |
| E5 | 对重尾变量比较均值 | 结论反转（注数案例） |
| E6 | 用全样本统计量做"预测" | 前视偏差 |
| E7 | 混淆"开出率"与"被选中率" | 因果解释错误 |
| **E8（v4 新增）** | **忽略规则变更，跨断点比较奖金** | 奖级编号/封顶/追加比例多次变化 → 结论无意义（见 `06_RULES_HISTORY.md`） |
| **E9（v4 新增）** | **用模拟去"验证"本可解析证明的事实** | 一等奖概率端到端模拟不可行；应解析给出（见 `07_strategy_simulation/`） |
