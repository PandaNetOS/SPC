## 6. 复现指引

本轮性质为整理入库，**没有新的统计计算**。可复现的是结构校验：

```bash

# 结构校验（28 项，含 SHA256 与红线恒值；r03 后扩展为 40 项）

# 从 FACTS.jsonl 重生成索引
python cli/main.py index

# 数据哈希复核（与 v4 原包对比）

# 期望: 9e92848e184c77154786bc376057f572333292010d3d3fba71ee53dd14706bb7
```
