> 版本规则见 `docs/VERSIONING_DOCS.md`

**数据**：2007-05-30~ 2026-10-07，共 2932 期（07001~26114）
**方法**：卡方/KS 拟合优度、ACF 自相关、FFT 谱分析、蒙特卡洛模拟（4000次）、马尔可夫检验、机器学习可预测性（OLS/Ridge/RandomForest，时序交叉验证）、泊松 GLM、多重比较 FDR 校正

## 一、核心结论（先看这个）

**没有可用于预测下一期的规律。** 但有3 个实质性发现，其中 1 个推翻了原数据包自带报告的核心结论。

| # | 发现 | 性质 |
|---|---|---|
| 1 | **前区号码频率偏差只存在于 2015 年之前**，2015 后完全回归均匀 | 制度性断点，历史冷热号已失效 |
| 2 | **连号组合的"被选中率"高 48%**，控制销量后依然显著 | 唯一可利用的真实效应（避坑） |
| 3 | **跨度窄、和值极端的组合中奖人数更多**；销量是压倒性主因（IRR=2.34） | 决定分奖人数，非概率 |

## 二、发现 1：前区频率偏差是"历史遗留"，不是规律

数据包自带报告称"前区卡方=89.3，频率显著偏离均匀"，并归因为"静态空间偏差（机台特征）"。**这个归因是错的。**

逐年卡方检验：

| 年份段 | 期数 | 前区卡方 | p 值 | 后区 p 值 |
|---|---|---|---|---|
| 2007 | 93 | 31.7 | 0.58 | 0.79 |
| 2009 | 153 | **86.8** | **1.6e-06** | 0.27 |
| 2012 | 154 | **86.6** | **1.8e-06** | 0.21 |
| 2014 | 154 | 25.9 | 0.84 | 0.50 |
| **2015** | 153 | 20.6 | **0.97** | 0.16 |
| 2017 | 153 | 37.5 | 0.31 | 0.10 |
| 2019 | 150 | 49.7 | 0.040 | 0.036 |
| 2020 | 134 | 34.6 | 0.44 | 0.20 |
| 2024 | 152 | 20.8 | 0.96 | 0.37 |
| 2026 | 114 | 27.8 | 0.76 | 0.85 |

**断点非常清晰**：2007-2014 频繁 p<0.01（2009/2012 达 p<1e-5），2015 起全部 p>0.2。

- 早期（2007-2014）29-35 号占比 **26.7%**，后期（2015-2026）**19.5%**（均匀应为 20.0%）
- 2×2 列联表卡方 = 105.72，p = **8.5e-25**
- 早期最热号 33/29/35/32/30/34/31 在后期全部回归 0.90~1.08 的正常区间
- 早期最冷号 16/4/15/8 在后期为 0.98/1.06/1.00/1.03
- 早期与后期的号码偏好向量相关 r = **-0.215**（p=0.21，不相关）

**含义**：早期存在设备或流程导致的偏倚（约 2009-2013 最严重），2015 年后已修复。因此"16 号最冷、29 号最热"这类结论**套用到当前已完全失效**——现在 35 个号等概率。

## 三、发现 2：连号效应（唯一可利用的真实规律）

### 3.1 现象

| 连号对数 | 期数 | 一等奖注数均值 | 中位数 |
|---|---|---|---|
| 0 | 1473 | 3.75 | 2.0 |
| 1 | 1308 | 3.79 | 2.0 |
| 2 | 137 | 5.33 | 3.0 |
| 3 | 14 | 7.21 | 5.5 |

含 2 对以上连号的期数，一等奖注数均值 **5.50 vs 3.77**（+46%）。

### 3.2 泊松 GLM（控制销量）

```
变量         系数      IRR     z       p
log_sale    +0.8508   2.342  +47.05   0.000***   ← 压倒性主因
run         +0.0812   1.085   +5.15   0.000***   ← 每多1对连号，注数×1.08
heat        +0.0249   1.025   +9.69   0.000***
sum_z       -0.0216   0.979   -2.17   0.030**
span_z      -0.0848   0.919   -8.09   0.000***
```

`run>=2` 的稳健估计：**IRR = 1.483，95% CI [1.382, 1.592]，p < 1e-16**（控制销量后仍显著）。

### 3.3 关键区分：开出频率 vs 被选中频率

连号组合的**开出占比**（观测 vs 理论）：

| run | 观测占比 | 说明 |
|---|---|---|
| 0 | 0.5024 | 与理论完全一致 |
| 1 | 0.4461 | 一致 |
| 2 | 0.0467 | 一致 |
| 3 | 0.0048 | 一致 |

**连号并没有更容易开出。** 差异 100% 来自"彩民更喜欢选连号"→ 被选中的注数多→ 中奖时撞号概率高。

**反向利用**：避开 2 对以上连号。中奖概率完全不变，但若中了一等奖，撞号概率显著降低。

### 3.4 其它分奖人数因子

- `span_z` IRR=0.919 → **跨度越宽，注数越少**（窄跨度组合更扎堆）
- `sum_z` IRR=0.979 → 高和值组合注数略少
- 销量 IRR=2.342 → 销量翻倍，注数×2.34，是唯一主导因素

## 四、被证伪的"规律"

### 4.1 和值一阶自相关 p=0.023 —— 假阳性

| 检验 | 结果 |
|---|---|
| 全样本 ACF L1 | r=+0.0418, p=0.0235 |
| 分段（每5年） | p = 0.52/0.63/0.45/0.34/0.51 全部不显著 |
| 剔除5%极端值 | r=+0.0288, p=0.159 |
| 蒙特卡洛 3000 次 | 观测值位于第 **98.8** 百分位，标准差 0.0182 |
| **BH-FDR 校正（150 个检验）** | L1 未通过；仅 lag=6/10/18/23 幸存 |

各分段 p 值完全不显著 + 剔除极端值后消失 = 由少数异常期驱动的偶然波动。

### 4.2 冷热号延续 —— 无效

前半程 TOP8 热号（22,30-35）在后半程出现 1408 次，期望 1675 次 → **低于期望**。冷号同样无延续。追热追冷都没有优势。

### 4.3 相邻期重号 —— 完全符合随机

- 上期含 a → 下期仍含 a：14.53% vs 理论 14.29%，**z = +0.84**（不显著）
- 平均重号 0.7264 vs 理论 0.7143，**z = +1.45**（不显著）

### 4.4 周期性 —— 无

去趋势 + 一阶差分后 FFT（2~80 期）：和值、销量、奖池**均无显著谱峰**。最高谱峰周期 1283 期远超样本容许。

### 4.5 机器学习可预测性 —— 零

| 模型 | 时序 CV R²（预测下期和值） |
|---|---|
| OLS | **-0.0750** ± 0.051 |
| Ridge | -0.0749 ± 0.051 |
| RandomForest | -0.2963 ± 0.116 |

全部为**负** R²（比直接猜均值还差）。

单号分类（35 个号，前 70% 训练 / 后 30% 测试）：**AUC 均值 = 0.5057**，区间 [0.450, 0.548]。随机基准 0.5。

### 4.6 星期效应 —— 无

单因素 ANOVA F=1.049, **p=0.350**；星期×奇偶列联表 p=0.902。和值按星期：周一 92.43 / 周三 91.74 / 周六 90.95。

### 4.7 组合冷热 —— 无经济价值

原报告称"冷组合降低中奖注数"。泊松 GLM 中 `heat` 系数虽显著，但 IRR=1.025（每升高1单位仅 +2.5%），远小于销量的影响；且原始 Pearson r = **-0.0017, p=0.93**。原结论基于重尾分布的均值比较，不可靠。

### 4.8 前后区耦合 —— 基本独立

- 和值 vs 后区跨度 r=+0.0001, p=0.995
- 大号个数 vs 后区跨度 r=-0.0015, p=0.933
- 奇偶 × 大号 个数卡方 p=0.094 → 独立

### 4.9 奇偶分布的偏离是早期现象

3奇2偶 实际 1070 期 vs 理论 940.9（z=+4.21），全期卡方 p<1e-6。但分段占比：2007-2014 约 65.6%，2015+ 约 66.6%~69.9% ——偏离主要来自早期设备偏倚（29-35 中奇数多）。

## 五、唯一可靠的分布规律（用于选号结构对齐）

这些**不改变中奖概率**，只让选号落在主流形态上。

| 项目 | 主流区间 | 占比 |
|---|---|---|
| 前区和值 | 62~120（10%~90%分位） | 80% |
| **和值最优区间** | **75~105** | **50%** |
| 奇偶比 | 3奇2偶 或 2奇3偶 | 67% |
| 大小比（大≥18） | 3大2小 或 2大3小 | 64% |
| 连号 | **0 对连号为最大众形态** | 50.2% |
| 三区比(1-12/13-24/25-35) | 2-1-2 / 2-2-1 / 1-2-2 | 41% |
| 后区奇偶 | 1奇1偶 | 56% |
| 后区跨度 | 1~4 | 56% |
| 和值高(≥120)时三区比 | 0-2-3 为主 | 34% |
| 和值低(≤62)时三区比 | 3-2-0 为主 | 29% |

### 后区 66 组合：完全随机

- 卡方均匀性 **p = 0.505**（12 个单号 p=0.499）
- 频次范围 31~60 次，理论均值 44.42
- 最热：3+10(60次)、2+7(59次)、5+7(56次)
- 最冷：3+5(31次)、6+11(34次)、2+3(34次)

**66 种后区组合无冷热差异**，选"冷后区"不提高中奖率。

## 七、最终建议

### ✅ 值得做的（真实提升期望收益）

1. **避开 2 对以上连号** —— 中奖注数多 48%，避开可显著降低撞号
2. **避开窄跨度组合**（如全部集中在 1-12）—— IRR=0.919，注数偏多
3. **避开极端和值**（>120 或 <62）和极端奇偶比（5:0 / 0:5）—— 扎堆
4. **避开生日号区**（1-31 密集，尤其 1-12）—— 这是彩民选号偏好，与连号效应同源

### ❌ 无效的（不要浪费钱）

1. 追冷号/ 追热号 / 遗漏值 —— z值不显著
2. 用历史频率选"低概率号" —— 2015 年后已完全均匀
3. 按星期、按周期选号 —— p=0.35/ 无谱峰
4. 任何 ML 模型 / 神经网络 —— CV R² 为负，AUC=0.506
5. 选"冷后区" —— p=0.505

原数据包自带的 `pattern_analysis_results.txt` 结论方向正确（序列独立随机），但两处表述需修正：
