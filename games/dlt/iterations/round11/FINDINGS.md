## 一、T-023 效应弱化的滚动复验（Q-011 → F-0042）

**问题**：后段 CI 下界逼近 1，E6 内效应会否继续弱化至不显著（Q-011）？

**方法**：后段（2013-08-28 起，1973 期）滚动窗口 W=300/500（步长 50），每窗算连号撞号比
R_run = mean(w1|run>=2)/mean(w1|run==0)，对窗口序列做 OLS 趋势 + Kendall tau + 头/尾 1/3 窗口
Mann-Whitney；节假日窗口（春节精确映射 ±14 天）分三时段（2008-14 / 2015-19 / 2020-26）对比。

**结果**：
- W=300：34 窗，slope=-0.0027（p=0.136），tau=-0.077（p=0.524），头均 1.083 vs 尾均 1.037（p=0.646）
- W=500：30 窗，slope=-0.001（p=0.401），tau=-0.044（p=0.750），头均 1.039 vs 尾均 1.031（p=0.910）
- 节假日窗口 R：2008-14=0.385（65 期）、2015-19=1.217（47 期）、2020-26=0.888（52 期），
  各段全年基线 ~1.04-1.15

**结论（F-0042）**：后段内部连号撞号效应**进入平台期**——2013-08 前段→后段的大幅弱化
（F-0003: 2.107→1.247）之后，效应不再持续弱化（R_run 稳定于 ~1.0-1.1，所有趋势检验不显著）。
**F-0003 无需新增弱化标注**（Q-011 验收判据："若趋势持续才标注"——趋势不持续）。
节假日效应分时段波动无单调弱化趋势，样本有限标探索性，不推翻 H-006。

## 二、T-024 机选占比的代理变量（Q-015 → F-0043）

**问题**：数据集无投注方式字段，机选占比能否用代理量观测（Q-015）？

**方法**：用**中出注数 w1**（而非开出号码——L7：避免混淆开出率与被选中率）构造 3 个代理：
P1 生日号区一等奖注数比 R_low = mean(w1|前区max<=31)/mean(w1|max>=32)；
P2 连号一等奖注数比 R_run（即 F-0003 的 R）；
P3 w1 号码偏好度基尼（按号码累加 w1 → 基尼，越低越均匀=机选主导）。
后段滚动 W=300 步长 50，数据驱动变点扫描（置换检验 B=2000，L3 不硬切）。

**结果**：
- P1 R_low：变点 p=0.055（不显著），头 1.245 → 尾 1.167 → **全段稳定 ~1.2**
- P2 R_run：变点 **p=0.0005**，头 1.231 → 尾 1.009，切点窗口起点 2015-04
- P3 gini_w1：变点 **p=0.0005**，头 0.144 → 尾 0.118，切点 2022-12
- R_low × 销量：r=-0.154（p=0.384，不显著）

**结论（F-0043）**：
1. **代理可观测**：连号偏好弱化（P2 显著变点，2014-15，与 F-0021 行为变化区间 2013-04~2014-04
   在滚动窗分辨率 ±24 月内**同窗对齐**）——F-0021 的『行为变化』通道存在且部分可检验；
2. **近年偏好浓度下降**（P3，2022-23，显著）→ 机选占比或上升（方向推断，非直接测量，L6 禁预测）；
3. **低号偏好未弱化**（P1 稳定 ~1.2）→ R-003 避开生日号策略的撞号优势可能依然成立；
4. 代理×销量不显著 → 与 F-0021 一致，效应非销量稀释。

**处置**：F-0021 caveats 更新（补 F-0043 代理证据 + 概率口径限定"各奖级恒定，一等奖恒 1/21,425,712"）。

## 三、T-048 L3 组合优化的时序 Hold-Out 评测设计（设计文档）

产出 `round11/T048_HOLDOUT_DESIGN.md`（**本轮只做设计，不落 L2**）：
- 数据切分：后段 1973 期 → 训练 60% / 验证 20% / 测试 20%（测试窗只评估一次）
- 指标：expected_bonus_given_win（主）、撞号系数 cf、每元回报 (1+m)/(K+m)、奖级概率恒定性

- 引用陷阱：F-0004/F-0029 是奖金提升非概率提升，禁止『提高中奖率』字样（validate 自动拦截）
- 验收：R_new 测试窗提升 > R-003 基线且 CI 不含 0 + 验证窗方向一致
