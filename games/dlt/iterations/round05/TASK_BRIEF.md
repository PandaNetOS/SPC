## 1. 目标

### T-201（最高优先）—— 前段（<2013-08）不自洽的根因与处置

**问题：F-0019 的三项异常，根因是数据记录、销售口径，还是当年真实的摇奖/结构差异？**

| 若根因是 | 应采取的动作 |
|---|---|
| 数据记录错误（中出注数或号码被错录） | 修正/排除该段 → 所有含前段的结论降级为「历史口径」，并重算 F-0003/F-0018/F-0004 的全样本数字 |
| 销售额字段口径不同（如只含基本投注、或早期统计口径不同） | 保留号码类结论，但**金额/注数类**结论必须分时段声明 |
| 当年真实存在的结构差异（如摇奖设备/球组） | 修改 `H-003` 的状态说明，并把「前段不可比」写入数据 caveats |

**方法方向（不预设答案）**：
1. **内部一致性三角核对**：用同一套恒等式（奖级概率 × 注数 × 单注金额）在三处互相验证 ——
   ① `prize1_winners` × `P1` 与 `prize2_winners` × `P2` 是否给出同一注数；
   ② 注数 × 最低票价是否 ≤ 销售额；
   ③ 一/二等奖单注金额与奖池分配公式是否自洽（按 epoch 分段 —— L9）。
2. **异常的时间定位**：把上述不一致量按月/季画出来，判断是**单一时期**、**逐年漂移**还是**只在某类期次**。
   ⚠️ 不得按自然年硬切宣称断点（L3）；用数据驱动切点或滚动窗口。
3. **外部交叉核对（若允许联网）**：用官方历史公告或公开数据库重建若干期（抽样 ≥ 30 期，覆盖 2007–2013），
   比对号码与中出注数。**能排除什么比能证明什么更重要**：哪怕只能确认 10 期号码正确，也算缩小了范围。
4. **销售字段的元信息核查**：检查 `sale_yuan` 在早/晚段的分布断点（是否有量级跃迁、是否为含/不含追加）。

### T-202 —— 跨注规则 R-002 的幅度量化（Q-012）

**问题：`has_duplicated_structure == true`（组内前区结构同构）到底改变多少期望奖金？权重 0.5 从何而来？**

**方法方向**：用 F-0004 的人群权重模型（α + 生日偏好）模拟「重复结构组」vs「多样结构组」的
条件期望中奖注数差；以 `data/derived/04_structure_distribution_exact.json` 的实际结构分布做人群抽样；
给出 `magnitude_pct` 点估计 + CI。**CI 含 0 → 标 `not_established`，权重应为 1.0（等于不 penalize）**。

### T-203（可选）—— 机选占比的代理变量（Q-015）

若 T-201/T-202 提前完成：尝试用「号码分布熵」「重复结构率」「低号占比」等时序量构造机选占比的代理，

## 4. 陷阱提醒

### 4.1 既有教训（必查）

| 教训 | 本轮哪里会踩 |
|---|---|
| **L13 口径自由度** | T-201 的「不一致量」本身有多种口径（聚合 vs 逐期、均值 vs 中位数）—— 结论必须写明用哪种，并做稳健对照 |
| **L14 分段自洽性前置检查** | 本轮**主题就是它**：任何跨段比较之前，先证明各段自身自洽 |
| **L3 变点禁自然年硬切** | T-201 的异常区间定位必须数据驱动（滚动窗口 / 全候选切点扫描） |
| **L9 禁跨规则断点比金额** | 早期段跨 E0/E1/E2 三个 epoch，奖金与奖级口径都变过 —— 金额类必须分段 |
| **L5 重尾禁止比均值** | `prize1_winners` 重尾（var/mean=8.46），前段尤其（零值率 40.6%）；中位数/截尾必须并列 |
| **L11 锚点不可反推** | 若要用「注数 × 票价 = 销售额」做核对，先核对三个量的口径是否同源 |
| **L10 条款 ≠ 发生** | 早期规则文本里的封顶/保底条款未必在数据里发生过 —— 先做事件计数 |
| **L7 开出率 ≠ 被选中率** | T-201 的号码分布异常是**开出**侧；不要用它论证人群偏好 |
