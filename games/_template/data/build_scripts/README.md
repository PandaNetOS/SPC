# data/build_scripts —— 派生数据重建脚本（模板占位）

从 `../raw/` 重建 `../derived/` 的脚本。

## 硬要求

1. **幂等**：跑两次输出的文件字节一致（注意固定排序、固定浮点格式、无时间戳）。
2. **自锚定路径**：用 `os.path.dirname(__file__)`，向上定位到包目录，再进 `raw/` 与 `derived/`。
3. **无网络、无外部状态**：只读 `raw/`，只写 `derived/`。
4. **失败要响**：数据缺列、行数不符、期号不连续，**直接报错退出**，不要静默跳过。

## 为什么强调幂等

派生数据集是结论的地基。若重建结果与提交版本不一致，
说明"可复现"是假的 —— 而本仓库的全部可信度建立在可复现上。

## 配套校验脚本

另写一个 `validate_package.py`，检查：

- raw 的 SHA256 与 `game.yaml` 登记值一致
- derived 文件齐全、行数符合预期
- 期号连续、无重复

把它接到 CI（`python cli/main.py validate --game <id>`）。
