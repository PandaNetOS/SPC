# data/derived —— 派生数据集（模板占位）

由 `../build_scripts/` 从 `../raw/` **机械可重建**的数据集。

## 原则

- **每一个派生文件都必须能从 raw 一键重建。** 建不出来 = 不是派生，是手工产物，不该放这里。
- 派生脚本必须幂等：跑两次结果字节一致。
- 派生文件不进 git 也没关系（若体积大），但**脚本必须进 git**。
  判断依据：`game.yaml` 里登记了 SHA256 的才需要进 git。

## 约定

- 文件名前缀数字表示依赖顺序：`01_xxx` → `02_xxx`。
- 每个文件在 `game.yaml` 的 `data.derived[]` 登记：路径、来源脚本、行数。

## 典型内容

| 类型 | 例子 |
|---|---|
| 精确理论分布 | 全部组合的形态分布（可精确枚举时） |
| 分段统计 | 按规则 epoch 分段，**不按自然年硬切**（教训 L3） |
| 检验结果表 | 供 FINDINGS 引用的原始数字 |
