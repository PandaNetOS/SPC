# data/tools —— 彩种分析脚本（模板占位）

**可直接运行的**检验与分析脚本。

## 与 build_scripts/ 的分工

| 目录 | 职责 | 判定 |
|---|---|---|
| `tools/` | 产生**认识**：检验、估计、诊断 | 输出结论或中间统计量 |
| `build_scripts/` | 产生**数据**：从 raw 重建 derived | 输出文件，幂等 |

一个脚本只做一件事。检验脚本不要顺手写数据文件。

## 硬要求

1. **脚本必须可直跑**：`python data/tools/xxx.py` 就能出结果，无参数也能跑。
2. **路径必须自锚定**：用 `os.path.dirname(__file__)` 定位，不依赖调用时的 cwd。
3. **输出必须落盘**：结果写 JSON/CSV 到 `../derived/`，不要只 print。
   否则结论无法被复核。
4. **随机过程必须固定种子**，并在输出里记录种子值。
5. **脚本路径写进结论的 `evidence.script`** —— 校验器会检查文件存在。

## 引用前自查

脚本对应的结论是什么？它落在哪一类证据？

- 解析可证 / 精确枚举 / 观测+CI / 模型估计

**这四类绝不可混淆**（教训 L8：禁用模拟去"验证"解析事实）。
