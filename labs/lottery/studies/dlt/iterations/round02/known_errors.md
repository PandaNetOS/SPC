## E1 — heat（组合冷热）被误判为"统计显著"

### 错误结论原文

> 泊松 GLM 输出：`heat coef=+0.0249 IRR=1.025 z=+9.69 p=0.000` → 结论"heat 显著"

同一报告另一处又写"无经济价值"，**自相矛盾**。

### 错在哪

| 层面 | 问题 |
|---|---|
| **模型族** | 因变量 `prize1_winners` 的 **方差/均值比 = 8.46**（Poisson 要求 = 1），严重过度离散 |
| **变量共线** | heat 与 `sum_z`、`span_z` 高度相关 |
| **定义敏感** | 换 heat 定义后系数符号会翻转 |

### 正确结论

**heat 无稳健效应 → 伪显著。**

证据链（已在 2933 期复核）：

1. **HAC/Newey-West 稳健标准误下 heat 失效**

   | maxlags | heat coef | se | t | p |
   |---|---|---|---|---|
   | 0 | +3.258 | 1.350 | +2.41 | **0.0158** |
   | 5 | +3.258 | 1.686 | +1.93 | 0.0533 |
   | 10 | +3.258 | 1.760 | +1.85 | 0.0641 |
   | 20 | +3.258 | 1.807 | +1.80 | **0.0714** |

   随滞后阶数增加，t 值从 +2.41 跌至 +1.80，**p 从 0.016 升到 0.071 → 不显著**。

2. **注意（v4 补充）**：在 QuasiPoisson/NegBin2 下 heat 系数仍"显著"
   （QP p=3.8e-8，NB p=2.6e-11），但这**不能**作为 heat 有效的证据 ——
   因为本文件所用 heat 是**全样本口径**（含前视偏差 E6），它本质上是
   "该组合在**未来**是否高频出现"的代理，与销量强混杂。**决定性判据仍是 HAC 与分期稳定性。**

3. **定义敏感性**：换"冷热"定义符号会翻转（历史案例：IRR 1.053 vs 0.842）。

### 复现方法

```bash
cd 03_tools && python overdispersion_and_hac.py
```

## E2 — 奇偶分布"显著偏离"（实为不显著）

### 错误结论原文

> "奇偶分布卡方 = 44.49, df=5 → p=0.0000 → 偏离"

### 错在哪

用**渐近卡方**检验，但 "0 奇" 格的期望频数仅约 56，该格对卡方统计量的贡献被错误放大。

### 正确结论

**精确蒙特卡洛检验：χ² = 8.85，经验 p = 0.126 → 不显著**（2933 期复核）。
奇偶分布与超几何理论一致。

| 奇数个数 | 观测（2933 期） | 理论 |
|---|---|---|
| 0 | 48 | 55.9 |
| 1 | 366 | 387.1 |
| 2 | 897 | 940.0 |
| 3 | 1070 | 1002.7 |
| 4 | 472 | 470.0 |
| 5 | 80 | 77.4 |

### 复现方法

```bash
cd 03_tools && python exact_tests.py     # 见 [5.3b] 段
```

## E3 — 断点定位错误：2015 → 实为 2013-08

### 错误结论原文

> "**2015 年**之前前区卡方全部 p<0.01；2015 年起全部 p>0.2。"

### 错在哪

**按自然年硬切**。未做切点扫描。

### 正确结论（2933 期复核）

**全候选切点扫描（t=300..2633，步长 10，共 234 个候选）显示最优切点为
2013-08-28（χ²=185.0），排名 1/234。**

| 候选切点 | χ²（2×35 列联表） | p | 排名 |
|---|---|---|---|
| t=960 → **2013-08-28** | **185.0** | 1.13e-22 | **1 / 234** |
| t=950 → 2013-08-05 | 183.7 | 1.87e-22 | 2 |
| t=980 → 2013-10-14 | 182.6 | 2.98e-22 | 3 |
| t=1168 → **2015-01-03** | 154.9 | 2.33e-17 | 远低于首位 |

**独立验证（ruptures）**：
- 精细扫描 800-1300 → 最优 t=955 = **2013-08-17**（χ²=185.9）
- Pelt（35 维信号, pen=10/15/20）→ 单变点 **2013-08-14**
- 高区(29-35)占比 Binseg → 2011-05-07, **2013-08-26**, 2018-06-11

**分期结果**：切点 2013-08 前段 χ²=251.5（p=5.2e-35），**后段 χ²=32.1（p=0.562）→ 已均匀**。

**性质**：卡方曲线在 2013-08 附近是**宽峰**（t=930~1000 均很高），
说明是**渐变过程**而非单点突变，切点有 ±6 个月不确定性。

**v4 追加强化**：2013-08 前后**无规则变更**（最近的是 2013-12-09 资金比例调整），
因此可排除"规则变更导致号码分布突变"这一假设 —— 号码结构 2007 年至今从未改变。

### 复现方法

```bash
cd 03_tools && python changepoint_scan.py && python changepoint_refine.py
```

## E4 — ACF 存活 lag 被误判为"真周期"

### 错误结论 / 矛盾

> 全样本和值 ACF lag1: r=+0.0418, p=0.0235（"显著"）
> 分 5 段后全部不显著
> **但 BH-FDR 校正后，和值 lag 6/10/18/23 反而存活**
> → 报告自己承认"矛盾点……未彻底查清"

### 错在哪

把"FDR 存活"直接等同于"真周期"，未做**置换检验**，也未检查**样本外预测能力**。

### 正确结论（2933 期复核）

**这些 lag 是"真信号，但真无效"。**

1. **置换检验确认不是假阳性**（10000 次打乱序列）

   | lag | 观测 r | 置换经验 p |
   |---|---|---|
   | 6 | +0.0664 | 0.0002 |
   | 10 | +0.0591 | 0.0009 |
   | 18 | +0.0616 | 0.0004 |
   | 23 | +0.0701 | 0.0003 |

   家族联合检验（max\|r\|）：**p = 0.0004**

2. **分期不稳定** —— 4 个 lag 分属不同时期（同号段数仅 3~4/5），
   彼此不是同一物理机制 → 是**分段结构变化的副产物**。

3. **与开奖日历不对应**：若为"每周 3 期"周期，lag=3/7 应更强，实测不然。

4. **决定性判据 —— 样本外预测失败**：

   | 模型 | 全样本 R² | 前半训练→后半测试 R² |
   |---|---|---|
   | lag=6 | 0.0045 | **−0.0839** |
   | lag=10 | 0.0035 | −0.0840 |
   | lag=18 | 0.0039 | −0.0835 |
   | lag=23 | 0.0050 | −0.0830 |

   **只要做真正的时间序列外推，R² 立即为负。**

**实用含义**：即使 R²=0.005 成立，和值预测标准差仅缩窄约 0.25%，
对 4.667e-08 的一等奖概率无任何可检出影响。

### 复现方法

```bash
cd 03_tools && python acf_permutation_test.py
```

## E5 — 重尾变量比较均值（注数）

### 错误做法

用**均值**比较"冷组合 vs 热组合"的一等奖注数，得出"冷组合中奖人数显著更少"。

### 错在哪

`prize1_winners` 是**重尾分布**（均值 3.86 / 中位 2 / 最大 106 / var/mean = 8.46）。
均值受极端值主导。

### 正确做法

- 用 **中位数 / 分位数**描述
- 用**非参数检验**（Mann-Whitney U）或 **GLM**（含过度离散校正）
- 报告效应量时用 **IRR** 而非均值差

> ⚠️ **v4 自我审视**：`07_strategy_simulation/` 的 B2 层为求直观用了**均值比**，
> 这本身触及 E5 风险。其缓解措施是：同时用**两个奖级**（一等奖样本小、二等奖样本大）
> 交叉确认，且给出 Bootstrap CI。改进方向见 `07_strategy_simulation/README.md` §9。

## E6 — 前视偏差（用全样本统计量做"预测"）

### 错误做法

用**全样本**的号码历史频率定义每期的"冷热"，再检验其对中奖注数的影响。

### 错在哪

第 t 期的 heat 用到了第 t 期之后的数据。

### 正确做法

```python
# 严格版：只用"截至上期"的历史
cum = np.zeros(36)
heat_past = np.full(n, np.nan)
for t in range(n):
    if t >= 100:
        heat_past[t] = cum[F[t]].mean() / (cum[1:].sum()/35)
    for v in F[t]: cum[v] += 1
```

> 注意：`03_tools/_load.py` 中的 `heat` 是**全样本口径**（仅为复现历史讨论），
> **做预测性分析时必须改为滚动口径**。

## E7 — 混淆"开出率"与"被选中率"

### 错误结论原文

> "连号组合的**开出占比**（观测 vs 理论）：run=0: 0.5024 / 理论 0.5024 → **完全一致**"
> "连号并没有更容易开出"

### 错在哪

理论值取自**错误的近似口径**（未枚举全部组合）。

### 正确结论（2933 期复核，精确枚举 324632 组合）

| run | 观测 | 精确理论 | 差 | z |
|---|---|---|---|---|
| 0 | 0.502216 (1473) | 0.523396 (1535.1) | −0.0212 | −2.30 |
| 1 | 0.398227 (1168) | 0.387701 (1137.1) | +0.0105 | +1.17 |
| 2 | 0.090351 (265) | 0.083079 (243.7) | +0.0073 | +1.43 |
| 3 | 0.009206 (27) | 0.005730 (16.8) | +0.0035 | +2.49 |
| 4 | 0 (0) | 0.000095 (0.3) | −0.0001 | −0.53 |

合并 χ² = 7.096, **p = 0.0288**（MC 精确 p = 0.0284）。run≥2 开出率比值 = **1.120**。

**但分期后**：早期显著，后期 p=0.356 → 偏离主要来自早期，**不能作为当前可用规律**。

### 关键：两个概念必须严格分离

| 概念 | 含义 | 数值 | 可用性 |
|---|---|---|---|
| **被选中率** | 彩民选号倾向选连号 | run≥2 期中奖注数 **×1.36** | ✅ **可避开** |
| **开出率** | 连号是否更易被摇出 | 1.12（仅早期，边缘） | ❌ 不可用 |

### 复现方法

```bash
cd 03_tools && python consecutive_exact_check.py
```

## E8 — 【v4 新增】忽略规则变更，跨断点比较奖金

### 错误做法

把全部 2933 期的 `prize1_amount_yuan` 放在一起算均值/建模型，
或把不同时期的"奖级注数"直接比较。

### 错在哪

超级大乐透自 2007 年上市共有 **6 次**规则调整（详见 `06_RULES_HISTORY.md`），其中：

| 变更 | 影响 |
|---|---|
| 2014-05-05（14052） | 奖级 8 → 6 |
| 2019-02-18（19019） | 奖级 6 → 9；追加 60% → 80%；追加分配范围改变 |
| **2026-02-02（26014）** | 奖级 9 → 7；**一二等单期总额封顶 1 亿元**；返奖率 50% → 51% |

**奖级编号体系变了 3 次**，"奖级 n 的注数"在不同时期含义不同；
封顶规则从 800 万 → 1000 万 → 1800 万 → 1 亿总额多次变化，
**奖金金额不可跨断点直接比较**。

### 正确做法

1. 涉及奖金/奖级的分析**必须按 epoch 分段**（`02_derived/08_rules_epoch_summary.json` 已给出 7 段）；
2. 明确声明所用规则版本；
3. **号码类分析除外** —— 前区 35 选 5、后区 12 选 2 的物理结构**从未改变**，
   号码分布分析可跨全期合并。

### 复现 / 参照

`06_RULES_HISTORY.md`、`02_derived/08_rules_epoch_summary.json`。

## E9 — 【v4 新增】用模拟去"验证"本可解析证明的事实

### 错误做法

写一个大循环模拟"技巧选号 vs 随机选号"的一等奖命中，试图"证明"技巧无效或有效。

### 错在哪

一等奖概率 = 4.667e-08。要观察到足够的命中次数，需要 **10⁸ 量级**的样本；
在有限算力下，命中数几乎恒为 0，结论完全由采样噪声主导 —— **既证不了也驳不了**。

更根本的是：**选号方式不改变中奖概率是数学定理**，不需要也不应该靠模拟"验证"。

### 正确做法

| 主张类型 | 正确方法 |
|---|---|
| 概率不变性（选号不改中奖率） | **解析给出**（分母 = 21,425,712 固定） |
| 形态被摇出的频率 | **精确枚举**（324,632 组合全枚举） |
| 形态是否集聚人群（撞号） | **观测量 + Bootstrap CI**（历史注数） |
| 中奖时奖金如何变化 | **条件份额模拟**（唯一必须模拟的量）+ 显式假设声明 |
| "技巧 vs 随机"的统计可检验性 | **功效分析**，并区分"数学不可能"与"统计测不出" |

### 复现 / 参照

`07_strategy_simulation/README.md` 与 `strategy_simulation.py`。
