## 1. 目标

对前区 35 选 5 + 后区 12 选 2 的所有可解释形态（105 个）做系统撞号比筛选，找出
F-0041 之外**新的显著拥挤形态**，并产出候选规则清单。

具体：
1. 新增 6 个原语到 `platform/core/features.py`（同尾号/连号长度/等差三元组/集合计数/中心偏离/同尾聚集）

3. 写一个统一筛选脚本，对 105 个形态逐个计算：
   - 后段 1973 期撞号比（含形态期 vs 不含形态期的一等奖注数比）
   - Bootstrap 95% CI（B=2000，种子 20261012）

   - NB2 重尾校正（对显著形态复核）
4. 输出两批结果：
   - **候选清单**：CI 下界 >1 且分期同向 → 进第二轮严格验证
   - **证伪清单**：CI 含 1 或 n<30 → 记录为"无证据"

## 5. 陷阱提醒

| id | 为什么本轮要特别注意 |
|---|---|
| **L1** | 一等奖注数 var/mean=8.46，重尾。撞号比用 Bootstrap，不用渐近正态 |
| **L4** | 105 个形态 = 105 次检验，α=0.05 下平均 5 个假阳性。第一轮必须标 tentative，候选才进校正 |
| **L5** | 均值比可能被极端期主导。显著形态必须用中位数比/NB2 复核 |
| **L7** | 撞号比是"被选中率"（人买得多），不是"开出率"（摇得出）。报告必须明确 |
| **L3** | 分期用 2013-08-28 变点，不用自然年硬切 |
| **L2** | 高稀疏形态（n<30）直接标 INCONCLUSIVE，不硬报显著 |
