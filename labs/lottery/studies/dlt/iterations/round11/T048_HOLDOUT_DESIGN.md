## 1. 目标与边界

**目标**：为 L3「规则组合搜索 + 组合投注策略」建立**可重复、无泄漏、可验收**的评测框架，
替代 shadow game（影子实盘），在真实历史数据上以时序 hold-out 完成规则评估。

**组合搜索边界（硬约束）**：
- 搜索空间 = **选号分布**上的「人群密度避让」规则组合（避开连号 / 避开生日号 / 避开镜像对 / 避开等差序列等形态）；
- 组合只作用于**选号分布**，不改变任何奖级的中奖概率（各奖级概率恒定，红线）；
- 输出指标仍为 `expected_bonus_given_win`（中奖时期望奖金，含封顶模型 F-0017）；
- **三条红线不变**（MATH_BOUNDARY）：不提高中奖概率 / 不预测号码 / 不承诺回报。

**引用陷阱（必须遵守）**：F-0004/F-0029 是**奖金提升**而非概率提升。
任何 L3 文案、README、策略说明**禁止**出现「提高中奖率/中奖概率」字样——概率口径检查（validate
`_check_probability_calibration`）会自动拦截。

## 2. 数据切分（时序 Hold-Out）

```
全样本 2933 期
└─ 后段（2013-08-28 起，1973 期）← 数据自洽段（F-0019 后段可作基线）
   ├─ 训练窗  60%  ≈ 1184 期（2013-08 ~ 2020 年中）   规则拟合 / 参数搜索
   ├─ 验证窗  20%  ≈ 395 期（2020 年中 ~ 2023 年中）   规则选型 / 阈值调参（可多轮）
   └─ 测试窗  20%  ≈ 394 期（2023 年中 ~ 2026-10）    最终验收（只评估一次）
```

- **前段（2007-2013）不进入任何训练**：数据不自洽（F-0019），只作背景描述。
- 切点选在**年份边界附近**（2020-07 / 2023-07）便于复述；不允许用数据驱动变点**再调整**切点
  （否则测试窗信息泄漏进切分决策）。

## 3. 评估指标

| 指标 | 定义 | 基线参考 |
|---|---|---|
| **主指标** `expected_bonus_given_win` | 条件份额模拟（B 次抽样）× 奖金结构（含 1 亿封顶 F-0017） | 随机池基线 = 全额期望；R-003 = +41.8%（锚点 n0=6） |
| 撞号系数 `cf` | 条件份额 / 随机份额（避开形态的撞号程度） | 随机 1.005 → R-001 0.476 → R-003 0.425（F-0029） |
| 每元回报比 | (1+m)/(K+m)，m=同号注数锚点（F-0027） | K=1: 1.000；K=2: 0.875；K=5: 0.636 |
| 奖级概率恒定性 | 1-9 等奖注数占比 vs 理论表（T-050） | 全奖级恒定，任何规则不得改变 |

**判定标准**（L3 落地验收）：
- `R_new` 在**测试窗**的 `expected_bonus_given_win` 提升 **> R-003 基线**，且 95% bootstrap CI 不含 0；
- 测试窗提升与验证窗提升方向一致（无过拟合翻转）；
- 三个固定基线（随机 / R-001 / R-003）在测试窗重算，作为同一评审批次的对照。

## 4. 防泄漏规则（L6 前视偏差硬约束）

1. **特征时间一致性**：任何特征（滚动窗口统计量、奖池、销量、锚点 m）在 t 期评估时，
   只能使用 **t 期及之前** 的信息；测试窗的锚点参数**冻结在验证窗末值**，不随测试窗更新。
2. **单次评估纪律**：测试窗**只评估一次**——规则拟合与选型只能在训练/验证窗进行；
   测试窗结果作为最终验收，不允许"看了结果再调参重跑"。
3. **切分封闭**：切点固定后不可因测试窗表现调整；如需多轮迭代，采用 walk-forward 滚动再训练
   （训练窗向前滚动，每步只评估紧邻的下一窗，窗口外数据永不进入拟合）。
4. **参数未用未来统计量**：如「近年机选占比上升」（F-0043）类信息用于规则选择时，
   只能以训练窗内估计为准。

## 5. 组合搜索协议（L3 落地时执行）

- 搜索算子：形态避让规则（run=0、max>=32、镜像对排除、等差序列排除……）的**可枚举组合**，
  每个组合 = 一个选号子池（继承 F-0029 的组合池枚举方法：run=0 169,911 个 52.3%；
  run=0 且 max>=32 89,181 个 27.5%）。
- 搜索指标：验证窗 `expected_bonus_given_win`（含封顶）+ 子池规模下限（避免过度收缩选号空间）。
- 输出：`R_new` 规则集 + 其验证窗/测试窗效应量 + 推荐投注方式（单注/复式/胆拖/倍投的
  K 注摊薄校准，F-0027）。
- 与 T-048 并行约束：任何组合**不得改变开奖概率**，文案语言受概率口径检查强制约束。
