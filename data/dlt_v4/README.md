| 层 | 主张 | 结论 | 可信度 |
|---|---|---|---|

## ⚠️ 三条最重要的红线

1. **`draw_num` 必须强制字符串**：`dtype={'draw_num': str}`，
   否则 `'07001'` → `7001`，期号匹配/排序/分段全错。
2. **CSV 必须用 `utf-8-sig`**：否则首列名变成 `'\ufeffdraw_num'`。
3. **不要用模拟"验证"数学定理**（见 E9）：
   选号不改变中奖概率是**解析结论**，端到端模拟在有限算力下不可行。

## 🔒 防污染机制

| 机制 | 实现 |
|---|---|
| 任务书不给结论 | `00_TASK_BRIEF.md` 只给事实与陷阱 |
| 错误结论集中隔离 | `05_known_errors.md`（E1–E9） |
| 历史产出隔离 | `03_findings/_legacy/`，且有使用门槛 |
| 要求主动证伪 | 交付必须列出"推翻/修正了哪些既有结论" |
| 冲突裁决规则 | 结论冲突时以**自身可复现证据**为准 |
