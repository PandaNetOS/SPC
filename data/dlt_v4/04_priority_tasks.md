## 全局约束

1. **先读 `05_known_errors.md`**，避免复述 9 个已知错误。
2. 每个结论必须**可复现**：给出脚本 + 原始输出数字。
3. **必须做过度离散检查**：任何计数因变量（注数、销量次数等）先算 `var/mean`，>1.5 则禁用 Poisson。
4. **必须做样本外验证**：任何"预测性"结论都要有时间序列外推的 R²/AUC。
5. **必须做分期稳健性**：任何结论至少在 `2013-08` 前后两段分别验证。
6. **必须声明规则口径**（v4 新增）：任何涉及奖金/奖级的分析，须声明所用规则版本
   （见 `06_RULES_HISTORY.md`），跨规则断点不得直接比较。
7. **必须区分"解析可证"与"模拟估计"**（v4 新增）：不要把模拟数字当作数学事实，
   也不要用解析结论掩盖需要估计的量（见 `07_strategy_simulation/README.md`）。

## T2 — 序列依赖性（预测层）

### T2.1 高阶自相关的置换检验

| 项 | 内容 |
|---|---|
| **研究问题** | ACF 中存活的高阶 lag 是真实依赖还是多重比较的产物？ |
| **方法** | ① 计算 ACF（注明去均值口径）；② **置换检验**（打乱 ≥10000 次）得每个 lag 的经验零分布；③ **家族错误率校正**（max\|r\| 联合检验）；④ **分期稳定性**；⑤ **样本外预测**（前 50% 训练 → 后 50% 测试，报告 R²） |
| **验收判据** | ① 置换经验 p；② 家族联合 p；③ 分期符号一致性；④ **必须报告样本外 R²** —— 若为负，结论必须是"无预测价值" |
| **预期产出** | `acf_reanalysis.md` |
| **已知参照** | 5 个 lag 通过置换（家族 p=0.0004）但样本外 R²=−0.083，判定"真信号、真无效"。请独立验证 |

### T2.2 非线性依赖与信息论检验

| 项 | 内容 |
|---|---|
| **研究问题** | 是否存在线性 ACF 检测不到的**非线性依赖**？ |
| **方法** | ① **互信息**检验；② **BDS 检验**；③ **Ljung-Box / McLeod-Li**；④ **转移熵** |
| **验收判据** | 每种方法给出统计量与 p 值；明确回答"是否存在非线性依赖" |
| **预期产出** | `nonlinear_dependence.md` |
| **备注** | BDS / McLeod-Li 属**新方向** |

### T2.3 机器学习的公平基线 ★重点

| 项 | 内容 |
|---|---|
| **研究问题** | ML 模型能否胜过"猜训练集均值"这个最朴素的基线？ |
| **方法** | ① 目标：预测 `front_sum`（回归）、单号是否出现（分类）；② 模型：OLS / Ridge / Lasso / RF / GBDT / LSTM；③ **严格时序 CV**；④ **必须对比 null 基线**；⑤ 报告 R²、MAE、AUC 及 CI |
| **验收判据** | ① 所有模型 vs null 基线的**配对比较**；② 明确报告"是否有任何模型显著优于基线"；③ 若全部分优于基线，明确写"序列不可预测" |
| **预期产出** | `ml_baseline.md` + 模型对比表 |
| **已知参照** | OLS R²=−0.075、RF R²=−0.296、AUC=0.506。上轮**未设 null 基线**，本轮必须补上 |

## T4 — 分奖结构（经济层）★重点

### T4.1 中奖注数的驱动因素（正确模型）

| 项 | 内容 |
|---|---|
| **研究问题** | 哪些号码结构特征会**提高中奖注数**（=提高撞号概率）？ |
| **方法** | ① **先做过度离散检验**；② 若过度离散用 **NegBin2 / QuasiPoisson**；③ 自变量：连号对数、跨度、和值、奇偶比、大小比、三区、销量；④ **HAC/Newey-West** 稳健标准误；⑤ **VIF 共线性诊断**；⑥ **Bootstrap CI**；⑦ **分期稳健性** |
| **验收判据** | ① 明确所用模型族及选择依据；② 每个变量给出 IRR + 95%CI + 稳健 p；③ 双重稳健性 |
| **预期产出** | `prize_winner_model.md` |
| **已知参照** | 连号 run≥2 → IRR=1.10（QuasiPoisson）/ IRR 达 1.36（分形态比值），分期稳健。**heat 在 HAC 下失效**（p=0.071） |

### T4.2 连号效应的独立验证（二阶变量）

| 项 | 内容 |
|---|---|
| **研究问题** | 连号效应是真实的彩民行为，还是单点噪声？ |
| **方法** | ① 用**二等奖注数**（样本量约 80 倍）复现；② 用**三等奖/四等奖**复现；③ 检验效应的**函数形式**（线性 run vs 门槛 run≥2）；④ 用**精确理论开出分布**分离"开出率"与"被选中率" |
| **验收判据** | ① 至少 2 个奖级同向；② 明确区分两个概念；③ 给出效应量的置信区间 |
| **预期产出** | `consecutive_effect_validation.md` |
| **已知参照** | 一等奖注数比 1.360 [1.130, 1.629]；二等奖注数比 1.352 [1.168, 1.579] → 两奖级同向确认 |

### T4.3 奖金瓜分机制建模 ★新方向

| 项 | 内容 |
|---|---|
| **研究问题** | 一等奖奖金如何在注数间瓜分？能否利用浮动期提高回报？ |
| **方法** | ① **右删失建模**：`prize1_amount_yuan` 81.4% 封顶 → Tobit / 删失回归；② 用一/二等奖注数**反推每期投注量**，与 `sale_yuan` 交叉验证；③ 检验瓜分公式；④ 识别**奖池累积期**的平台特征；⑤ **必须按规则 epoch 分段**（`02_derived/08_*`），因为封顶规则多次变化 |
| **验收判据** | ① 瓜分公式拟合结果；② 明确回答"是否存在高期望回报的投注时机"；③ 区分"单期期望"与"长期期望" |
| **预期产出** | `prize_pool_mechanism.md` |
| **v4 提示** | 现行规则下**一二等奖单期总额封顶 1 亿**，是判断"高期望期"的新关键约束 |

## T7 — 【必须交付】策略模拟验证 ★★★（v4 新增）

> **v4 的核心新增。** 目的：把 T6 的每条主张从"论断"变成"可复现的量化验证"。
>
> ⚠️ **铁律**：**不要用模拟去"验证"本可解析证明的事实**（见 `05_known_errors.md` E9）。
> 概率不变性用解析给出；只有"撞号/奖金"这类**必须估计**的量才用模拟，且必须报告假设与 CI。
>
> 参照实现：`07_strategy_simulation/strategy_simulation.py` + `README.md`。

### T7.1 建立四层验证框架

| 项 | 内容 |
|---|---|
| **要求** | 把策略主张按可验证性分层，每层用合适的方法，并标注可信度 |
| **必含四层** | **A 概率层**（解析：选号不改变中奖概率）<br>**B1 开出率层**（精确枚举：形态被摇出的理论 vs 观测）<br>**B2 撞号层**（观测数据：形态是否集聚更多彩民）<br>**C 经济层**（条件模拟：中奖时奖金如何变化）<br>**D 等价基线**（解析+功效：技巧 vs 随机无差异） |
| **验收判据** | 每层给出：方法、假设、数值结果、**可信度分级（★）**、以及"该层不是真值"的声明 |

### T7.2 撞号效应的量化与置信区间

| 项 | 内容 |
|---|---|
| **要求** | 用历史注数验证"连号形态人群更密"，并给 Bootstrap CI |
| **方法** | ① 按 run≥2 分组，比较同期一/二等奖注数比值；② **Bootstrap 独立重采样**给出 CI（⚠️ 勿用 a 的长度索引 b，会得到不可能的 CI）；③ 至少两个奖级交叉确认；④ 分期稳健性 |
| **验收判据** | 给出比值 + 95%CI；明确"CI 下界 > 1 才成立" |
| **已知参照** | 一等奖比 1.360 [1.130, 1.629]；二等奖比 1.352 [1.168, 1.579] |

### T7.3 经济价值估计（条件份额模拟）

| 项 | 内容 |
|---|---|
| **要求** | 在固定预算下，量化"避开高撞号形态"对"中奖时奖金"的影响 |
| **方法** | ① 声明为何不能端到端模拟（一等奖概率 4.67e-8）；② 建立**人群权重模型**并用历史数据**校准**（给出校准公式）；③ 条件份额模拟；④ Bootstrap CI；⑤ **必须列出减损项**（模型估计误差、封顶稀释、只在中奖时兑现） |
| **验收判据** | ① 给出奖金提升量 + CI；② **明确写出"不改变中奖概率"**；③ 给出收益上界与减损后的净值讨论 |
| **已知参照** | 撞号系数 1.003→0.453（比值 0.452 [0.449, 0.454]），奖金提升 +121% |

### T7.4 等价基线与功效分析

| 项 | 内容 |
|---|---|
| **要求** | 证明（并解释为何难以统计检验）"技巧"与随机策略的中奖概率相等 |
| **方法** | ① 模拟固定预算下两种策略的命中数；② 与理论期望对比；③ **功效分析**：检出 ε 相对效应所需期数 ~ 1/(p·ε²) |
| **验收判据** | ① 命中数均围绕理论期望；② **明确区分"数学上不可能"与"统计上测不出"** |
| **已知参照** | p_per_trial=4.667e-06，检出 1% 效应需 ~2.14e+09 期 |
