# 07_strategy_simulation — 策略模拟验证框架

> **本目录回答一个问题**：T6 购买策略里的每条主张，**能不能被模拟验证？验证结果是什么？可信度有多高？**
>
> 设计原则：**把"可解析证明"与"必须模拟估计"分开报告**，绝不用模拟去"验证"本可解析证明的事实，
> 也绝不用解析结论去掩盖只能估计的量。**不给出比证据更强的结论。**

---

## 0. 一句话结论表

| 层 | 主张 | 能否验证 | 结论 | 可信度 |
|---|---|---|---|---|
| **A 概率层** | 选号方式改变中奖概率 | ✅ **解析可证** | **不可能**（p 恒 = 4.667e-08） | ★★★★★ 数学定理 |
| **B1 开出率** | 连号更易被摇出 | ✅ 精确枚举为真值 | 观测与理论微差（run≥2 比值 1.12），**仅早期，不可用** | ★★★★☆ 枚举真值 |
| **B2 撞号层** | 连号形态人群更密 | ✅ 历史数据可测 | **成立**：一等奖注数比 1.360 [1.130, 1.629] | ★★★★☆ 观测+CI |
| **C 经济层** | 避开连号提高"中奖时奖金" | ⚠️ **只能条件模拟** | **成立**：撞号系数 1.003→0.453，奖金 +121% | ★★★☆☆ 依赖模型 |
| **D 等价基线** | "技巧" vs 随机 | ✅ 解析等价 | **无差异**（p 恒等），且统计上不可检验 | ★★★★★ 解析 |

> **最重要的红线**：C 层的 +121% 是"**中一等奖时的期望奖金**"提升，**不是**中奖概率提升。
> 两者绝不能混为一谈。任何把 C 层结论表述为"提高中奖率"的说法都是**错误**的。

## 1. 为什么分四层

彩票分析最常见的两类错误：

1. **用模拟"证明"数学事实** —— 一等奖概率是 1/2142万，端到端模拟要么算力无穷、要么结论噪声主导。
   凡解析可证的事实（概率不变性），**直接解析给出**，不用模拟。
2. **用解析结论掩盖估计量** —— "撞号系数"依赖彩民选号模型，这是**估计**，必须给模型、给假设、给 CI。

因此本框架：

```
A 概率层    → 解析（不用模拟）
B 撞号层    → 观测数据 + 精确枚举（半解析）
C 经济层    → 条件份额模拟（必须模拟，但显式声明模型假设）
D 等价基线  → 解析 + 功效分析（回答"为什么模拟也测不出来"）
```

## 2. 关键假设（必须显式声明）

| 编号 | 假设 | 依据 / 风险 |
|---|---|---|
| **H1** | 开奖为**独立均匀随机**（前区 C(35,5)、后区 C(12,2) 等概率） | 由历史检验支持（见 `05_known_errors.md` E1–E7）。**若存在可利用偏倚，全部结论失效** —— 但四轮检验均未发现可用的物理偏倚 |
| **H2** | 彩民选号**非均匀**：偏好连号、生日号（≤31）、低和值等 | 由 `prize2_winners`（二等奖注数，样本量约 80 倍于一等奖）与精确理论分布对比支持 |
| **H3** | "撞号人数"正比于"该组合被买注数"，用历史一/二等奖注数作代理 | 代理误差是 C 层主要不确定性来源 |
| **H4** | 奖金按**现行 7 奖级规则**（2026-02-02 起）计算 | 见 `06_RULES_HISTORY.md`。**跨规则断点的历史奖金不可直接套用** |

> ⚠️ **H2/H3 是估计，不是真值。** 本目录所有 C 层数字都受这两个假设约束，
> 报告中必须与 A/D 层的"数学事实"区分标注。

## 3. A 层：概率不可变性（解析）

```
单注组合总数 = C(35,5) × C(12,2) = 324,632 × 66 = 21,425,712
一等奖概率   = 1 / 21,425,712 = 4.667289469773513e-08
```

**选号方式作用于哪个量？**

- 分子（是否命中）由**开奖结果**决定 —— 选号方式无法影响开奖；
- 分母（是否与他人共享）由**他人选号**决定 —— 选号方式**可以**影响。

→ 因此"技巧"唯一可影响的，是**中奖时奖金的摊薄程度**（C 层），而非中奖概率本身。

**复现**：`strategy_simulation.py` 的 `report['A_probability_layer']`。

## 4. B 层：撞号效应是否真实存在

### B1 开出率（精确枚举，非模拟）

`run`（相邻号对数，如 12-13 算 1 对）的**精确理论分布**由枚举 C(35,5)=324632 全部组合得到：

| run | 精确理论 | 观测（2933 期） | 差 |
|---|---|---|---|
| 0 | 0.523396 | 0.502216 | −0.021 |
| 1 | 0.387701 | 0.398227 | +0.011 |
| 2 | 0.083079 | 0.090351 | +0.007 |
| 3 | 0.005730 | 0.009206 | +0.003 |
| 4 | 0.000095 | 0 | — |

合并卡方 p≈0.03，run≥2 比值 1.120，**但分期后仅早期显著**（见 `05_known_errors.md` E7）。
→ **开出率差异不可作为当前可用规律**。

### B2 被选中率（撞号代理，观测数据）

用**同期实际中奖注数**作为"该形态有多少人买"的代理：

| 指标 | run≥2 期均值 / run<2 期均值 | 95% CI（Bootstrap, 2000 次） |
|---|---|---|
| `prize1_winners`（一等奖注数） | **1.3603** | **[1.1298, 1.6292]** |
| `prize2_winners`（二等奖注数） | **1.3520** | **[1.1679, 1.5793]** |

n_ge2 = 292，n_lt2 = 2641。**两个奖级、独立样本、CI 下界均 > 1**
→ **撞号效应（被选中率差异）真实存在且稳健。**

> ⚠️ 注意 B1 与 B2 是**两个不同的概念**，不可混用（见 E7）：
> - B1 = "连号更易被**摇出**"（弱，仅早期）
> - B2 = "连号更易被**人买**"（强，稳健）
> 策略价值只来自 **B2**。

**复现**：`report['B1_run_open_rate']` / `report['B2_collision_proxy']`，
Bootstrap 函数 `ratio_and_boot()`。（早期版本有 bug：用 a 的长度索引 b 数组，
产生不可能的 CI [3.99, 7.33]，已修正为 a、b **各自独立重采样**。）

## 5. C 层：经济价值（条件份额模拟）

### 5.1 为什么必须"条件模拟"

一等奖概率 4.67e-8。若端到端模拟"中奖"，需要 ~10⁸ 量级样本才能看到寥寥几次命中，
**结论会被采样噪声完全淹没**。因此改用**条件期望法**：

> 给定"我们中了一等奖"这一事件，比较不同选号策略下**同期他人注数的期望**，
> 从而得到单注奖金的相对高低。

这个方法**不模拟"是否中奖"**（那是 A 层解析解决的），
只模拟**"中奖时奖金多少"**（这是唯一需要估计的量）。

### 5.2 人群权重模型与校准

```
权重 w(组合 c) = α        若 run(c) ≥ 2        （连号偏好）
              × 1.25     若 max(c) ≤ 31        （生日号偏好）
              = 1        否则
```

**α 的校准**（唯一自由参数，由历史数据锁定）：

```
R = 观测一等奖注数比值 = 1.3603          （来自 B2）
P_ge2 = 理论 P(run≥2) = 0.0889
P_lt2 = 1 − P_ge2     = 0.9111
α = R × P_lt2 / P_ge2 = 1.3603 × 0.9111 / 0.0889 = 13.9405
```

α 不是拍脑袋 —— 它使模型**恰好复现** B2 观测到的撞号差异。

### 5.3 模拟结果

对 300,000 次抽样，比较两种策略"条件中奖时的人群权重"：

| 量 | 随机选号 S_rand | 避开连号 S_norun |
|---|---|---|
| 条件撞号系数 | **1.0028** | **0.4528** |
| 比值（norun/rand） | — | **0.4515**，95%CI **[0.4487, 0.4543]** |
| 奖金提升 | — | **+121.48%** |

**解读**：避开连号使"中一等奖时与他人重号的期望注数"降到约 45%，
等价于**中奖时单注奖金提升约 1.2 倍**。

### 5.4 C 层的三道减损（必须写进结论）

1. **模型依赖**：α、生日偏好系数来自历史注数近似校准，是**估计**非真值。
2. **封顶稀释**：现行规则一、二等奖**单期总额封顶 1 亿**、单注最高 500 万（见 `06_RULES_HISTORY.md`）。
   若已触发封顶，减少同号人数**不再增加**单注奖金 → 实际收益 < +121%。
3. **只在中奖时兑现**：中奖概率 4.67e-8 不变，期望回报的提升被"中奖概率极小"大幅折现。
   以 2 元/注、返奖率 51% 计，**长期期望回报仍为负**（约 −0.98 元/注）。

**复现**：`simulate_conditional_share()` + `calibrate_run_weight()`。

## 6. D 层：等价基线与功效分析

**主张**：固定预算 100 注，"技巧"策略与随机策略的**中奖概率完全相等**。

200,000 次试验：

| | 命中数 | 理论期望 |
|---|---|---|
| 技巧策略 | 4 | 0.9335 |
| 随机策略 | 1 | 0.9335 |

两者都在理论期望附近波动，**无系统差异**。

**功效分析（回答"为什么模拟也测不出差异"）**：

```
要检出"技巧使概率提升 ε（相对量）"所需期数 ~ 1 / (p · ε²)
以 ε = 1% 计：~ 2.143e+09 期
```

历史彩票总量不足 3000 期 → **统计上不可检验**。

> ⚠️ **关键区分**：
> - "**数学上不可能**" = 解析结论（A 层），**确定**；
> - "**统计上测不出**" = 功效不足（D 层），只是说**这套数据无法检验**。
> 二者是**两回事**，报告不可互相替代。

**复现**：`simulate_strategy_equivalence()`。

## 9. 给下一个分析者的建议

**可改进的地方**（本框架明确未做到）：

1. **人群权重模型过于简化** —— 只用了"连号"与"生日号"两个特征。
   改进方向：用 `prize2_winners` 的全量数据做**真正的回归校准**（而非单一比值），
   把 35 个号的**逐号偏好向量**估出来。
2. **未处理一等奖注数的重尾** —— B2 用了均值比（重尾变量，见 E5）。
   改进方向：中位数比 / 负二项回归给出 IRR，作为稳健性对照。
3. **未做分期稳健性** —— B2 应至少在 2013-08 前后两段分别验证。
4. **C 层未纳入封顶机制** —— +121% 是"无封顶"上界，加入 1 亿总额封顶后的净值待估。
5. **后区撞号未建模** —— 后区 12 选 2，生日偏好对后区同样适用。

> 本目录的核心价值不在数字，而在**方法边界**：
> 哪些结论是真理（A/D）、哪些是强观测（B2）、哪些是受假设约束的估计（C）。
> **请不要把 C 层当作 A 层使用。**
